# Tirik Tarix — полная информация о проекте

**Слоган:** «Qahramonlar haqida o'qima — ular bilan gaplash»
(«Не читай про героев — поговори с ними»)

**Одной фразой:** бесплатная платформа, где дети Узбекистана изучают историю
страны, разговаривая с историческими личностями на узбекском языке.

**Статус:** участник President Tech Award (awards.gov.uz), трек инкубации.

*Все цифры в документе взяты из работающей базы данных 19 августа 2026 —
не из планов и не из старых презентаций.*

---

## Проблема

История в школе — это параграфы и даты, которые заучивают и забывают.
Контента об истории Узбекистана на узбекском языке в интерактивной форме
почти нет. А AI-чаты, которые «оживляют» исторических героев, выдумывают
факты — доверять им уроки истории нельзя.

## Решение и главный принцип

Ребёнок открывает «Зал предков», выбирает Амира Темура, Мирзо Улугбека или
Алишера Навои и задаёт вопрос своими словами. Герой отвечает от первого лица —
но с одним железным правилом:

> **«Sun'iy intellekt shaklni yaratadi — haqiqat uchun odamlar javob beradi»**
> AI создаёт форму — за правду отвечают люди.

Каждый ответ героя строится только из карточек фактов, проверенных
методистом-историком, и под ответом стоит источник. Если ответа в карточках
нет, герой честно говорит: **«Bu haqda tarix sukut saqlaydi»** («Об этом
история молчит»). Герой физически не может выдумать факт.

## Игровая механика

- **XP и стрики** за тесты, фильмы и ежедневную загадку (10 XP)
- **Маскот Илвирс** — снежный барс в парадном чапане с золотой тиарой:
  прячется за краем экрана, выпрыгивает радоваться успехам и грустит,
  если сегодня не занимался (в стиле Duolingo)
- **Аватары** — 32 предмета экипировки для персонажа ученика
- **Дуэли (Bellashuv)** — соревнования по знаниям между учениками
- **Таблица лидеров**
- **Озвучка на узбекском** — героев можно слушать, не только читать

## Дизайн — система «TEMIR VA ZAR» (Сталь и Золото)

Метафора — ночная крепость-музей: тёмный камень, золотая инкрустация,
пергамент в зонах чтения. Шрифты Cinzel («высечено в камне»), Inter,
Cormorant Garamond, Baloo 2. Логотип-медальон: портрет Сохибкирона в золотом
кольце на фоне Регистана. Переходы между разделами — «солнечный занавес»
(с отключением для светочувствительных детей через prefers-reduced-motion).

## Технологии

| Слой | Технология |
|---|---|
| Бэкенд | Java 17, Spring Boot 3.5, Flyway (107 миграций базы) |
| Фронтенд | Next.js 16 (App Router, TypeScript), Tailwind CSS 4 |
| База | PostgreSQL 16 |
| AI героев | Claude (Anthropic), официальный Java SDK |
| API | 27 REST-контроллеров |

**Админ-панель для методиста-историка** — отдельный контур из 10 разделов:
карточки фактов, герои, события, эпохи, карты, фильмы, тесты, пользователи,
статистика и **журнал аудита** (кто что изменил). Именно здесь живёт
«человеческая» половина принципа №1.

**Конвейер контента:** 30+ документированных промтов-инструкций
(docs/promt_*.md) для производства карточек, видео, портретов и озвучки —
контент делается поточно, но каждый факт проходит проверку человеком.

## Модель

**Социальный проект: полностью бесплатно.** Без подписок, рекламы и платных
функций. Язык — полностью узбекский (латиница): интерфейс, контент, голос.

Аудитория: ядро — школьники 10–15 лет; дальше — абитуриенты, учителя истории,
родители.
