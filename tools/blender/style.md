## Пропорции большого превью (Qurolxona)

ViewBox 240×320. Модуль — высота головы **U = 38px**; пол y=296; y = 296 − z·U.
Рост 7.5 голов (≈288px). Ключевые уровни (в U от пола):

| Точка | z (U) |
|---|---|
| Колено | 2.0 |
| Подол мужской туники | 2.9 |
| Пах | 3.55 |
| Талия/пояс | 4.75 |
| Грудь | 5.55 |
| Плечи | 6.05–6.12 |
| Подбородок | 6.5 |
| Центр головы | 7.02 |
| Макушка | 7.5 |
| Подол женского платья | 1.68 |

Полуширины (в U): плечо внешн. 0.94, грудь 0.78, талия 0.67, подол муж 0.80,
подол жен (A-силуэт) 0.89. Кисти висят на (±0.80U, z≈3.36U).

### Якоря экипировки (общие для ВСЕХ типажей — жёсткое правило из SVG)

## Фирменные элементы (по ним герой узнаётся)

Фигура:
- туника/платье с **воротником-стойкой**, тёмной планкой и 3 пуговицами;
- матерчатый **пояс с узлом и свисающим спереди концом**;
- мягкие кожаные **ковуши**;
- мужчины: **полная борода** + зачёс назад (amirzoda — короткая борода);
- женщины: **серёжки-точки zar**, причёски: две косы с золотыми завязками
  (jangchi-qiz, kochmanchi-qiz), пучок (malika, olima), распущенные (oddiy-qiz);
  kochmanchi-yigit — косичка на плече;
- золотая кайма подола у «дворцовых» (amirzoda, malika);
- rim-light цвета zar по контуру.

Стандартные головные уборы (рисуются только при пустом слоте HEAD):
- jangchi(-qiz): **peshonaband** — повязка с золотым/красным ромбом;
- sarkarda: высокий чёрный **qalpoq** с золотой лентой и красным пером;
- kochmanchi(-qiz): меховой **telpak**;
- amirzoda: белая **salla** (тюрбан) с камнем;
- malika: золотой **tillakosh** (тиара) с тремя рубинами;
- olima: тёмно-синий **qalpoq со звездой**;
- oddiy: без убора.

Предметы (все 32 из `avatar_items`, V11+V12; формы — из ITEMS в Character.tsx):
- **doppi** — чёрная тюбетейка с рядом золотых ромбов;

  у золотого — плюмаж-перо и свечение;
- **zar-toj** — зубчатая золотая корона с красным камнем;
- щиты — **круглые с концентрическими кругами** и центральной бляхой;
  у zar/oltin — 8-конечная звезда;
- **po'lat qilich** — прямой меч остриём вверх, золотая гарда, круглое навершие;
- **sohibqiron qilichi** — изогнутая сияющая сабля;
- **nayza / sarkarda nayzasi** — копьё (у саркарды — красный флажок);
- **kamon-sadoq** — лук в руке + колчан со стрелами у пояса справа;
- **ulug'bek kamoni** — лук со звёздами обсерватории;
- **oybolta** — секира с полумесячным лезвием;

## Правила стиля для 3D

- Низкополигональность: плоские грани, минимум деталей, простое лицо
  (брови, глаза-точки, нос; рот только у женщин — у мужчин борода).
- Материалы **матовые, без бликов** (roughness ≈ 1, specular 0);
  металлы экипировки — умеренный metallic, oltin чуть светится.
- Поза спокойная, A-pose, руки вдоль тела, оружие опущено. Детский стиль.
- Ортографическая камера, кадр 2:3 (512×768), прозрачный фон,
  один свет и одна камера на все рендеры (слои должны совпадать попиксельно).
- Телосложение по типажу: muscular (jangchi, sarkarda), athletic
  (kochmanchi, jangchi-qiz, kochmanchi-qiz), slim (amirzoda, malika, olima),
  average (oddiy-yigit, oddiy-qiz). Женские — уже в плечах, ниже ростом.
