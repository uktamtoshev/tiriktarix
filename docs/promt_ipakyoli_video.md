Найди в интернете обучающее видео/фильм **для детей и подростков** про Великий шёлковый путь и прикрепи его к карточке «Ipak yo'li: bir karvonning yo'li» в Кинозале. Только эта одна карточка. Схема работы — та же, что для «Avesto» (`docs/promt_avesto_video.md`): два этапа, реализация только после моего одобрения. Если для «Avesto» уже реализованы превью и модал-плеер — переиспользуй их без изменений.

## 0. Контекст

- Карточка в `backend/src/main/resources/db/migration/V8__films.sql`: эпизод «Ipak yo'li: bir karvonning yo'li» (SHORT, ~4 daq., сейчас без видео). Суть темы по описанию карточки: путь глазами одного каравана — какие товары везли, какие города стояли на пути (Samarqand, Buxoro, Xiva), и почему торговля была больше, чем торговля (обмен знаниями и культурой).
- Новую миграцию создавай следующим свободным номером после актуальных в `db/migration/`.

## Этап 1 — Поиск (WebSearch + WebFetch)

Ищи на YouTube и похожих платформах (Mover.uz, Vimeo, Dailymotion, Rutube, каналы узбекских ТВ и образовательных проектов). Формулировки:

- узбекский: «Buyuk ipak yo'li hujjatli film», «ipak yo'li tarixi bolalar uchun», «Buyuk ipak yo'li Samarqand Buxoro video», «ipak yo'li karvon savdo tarixi»
- русский: «Великий шёлковый путь документальный фильм для детей», «шёлковый путь Самарканд Бухара фильм», «шёлковый путь история торговли видео»

Критерии (все обязательны):

1. Образовательное: документалка, анимация или лекция; акцент на караваны, товары, города Центральной Азии — а не только Китай.
2. Подходит детям/подросткам: без жестокости; если скорее для старших подростков — пометь.
3. Не Shorts и не клип: ≥ 3 минут, URL без `/shorts/`.
4. **Оригинальный канал, а не пиратский перезалив** чужого фильма: перезаливы удаляют по жалобе — ссылка умрёт. Если фильм явно телеканала/студии — ищи его официальный канал.
5. Язык: узбекский приоритетен, русский допустим (с пометкой «RU»).
6. **Ссылка верифицирована WebFetch'ем**: реальный заголовок, канал, длительность, доступность. Ссылки «из памяти» запрещены; непроверяемая = отклонена.

Результат — таблица топ-3: `платформа | название | канал | язык | длительность | возраст | URL | плюсы/минусы`, рекомендация №1, отклонённые с причинами. **Жди моего «ок»**.

## Этап 2 — Реализация (после одобрения)

- Миграция: `UPDATE films SET video_url = '…', status = 'PUBLISHED', duration_minutes = <фактическая>, source = '<Платформа>: <канал>'` только для этой карточки; `verified = false` (методист отсмотрит).
- Список `/filmlar`: превью-кадр + запуск (YouTube → модал `youtube-nocookie`, iframe только после клика; иная платформа → внешняя ссылка с бейджем, `rel="noopener"`).
- Детальная карточка: блок просмотра с кнопкой «Ko'rish» и атрибуцией канала; шаг 4 конвейера для внешнего видео подписывай честно («Video biriktirildi (tashqi manba)»), не «Animatsiya tayyor».
- UI-текст — узбекская латиница.

## Ограничения и приёмка

- Трогать только эту карточку; схему `films`, старые миграции и остальные эпизоды не менять; новых зависимостей не добавлять.
- Приёмка: таблица показана до реализации; записанная ссылка открывается и совпадает по заголовку; `mvn test` и `npm run build && npm run lint` зелёные; карточка «Ipak yo'li» играет видео, остальные не изменились; в сводке — платформа, язык, возрастная пометка и напоминание методисту (verified=false).
