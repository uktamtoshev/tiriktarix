# Промт для Claude Code — портреты 10 предков в «Ajdodlar zali»

> Скопируй всё, что ниже разделителя, в Claude Code в корне репозитория TIRIK TARIX.

---

Подключи изображения к карточкам предков в галерее «Ajdodlar zali». Речь про десятерых: **Amir Temur, Mirzo Ulug'bek, Alisher Navoiy, Zahiriddin Bobur, Abdulla Qodiriy, Jaloliddin Manguberdi, Imom al-Buxoriy, Ibn Sino, Abu Rayhon Beruniy, Muhammad al-Xorazmiy.**

## 0. Важно понять до начала

**Фотографий большинства из них не существует** — фотография появилась в XIX веке. Реальные фотоснимки есть только у Абдуллы Кадыри (1894–1938). У остальных возможны только миниатюры, поздние живописные изображения или современные иллюстрации. Продукт стоит на принципе достоверности, поэтому **каждое изображение должно быть честно подписано**: миниатюра — миниатюрой, современная иллюстрация — современной иллюстрацией. Никогда не подписывай изображение как исторический портрет, если это не так.

Поля героя для этого уже есть (`Hero.java`, тип `Hero` в `lib/api.ts`): `portrait_url`, `portrait_kind` (`PHOTO` / `MINIATURE` / `ARTWORK`), `portrait_caption_uz`, `portrait_source`. Проверь их реальные имена в схеме и миграции V9 перед работой.

## 2. Два особых случая — реши со мной, не сам

- **Имам аль-Бухари.** Изображений его не существует, и в исламской традиции портретов таких фигур не делают. Не бери «портрет аль-Бухари» из интернета — почти наверняка это выдумка. Правильный вариант: **фото мемориального комплекса в Самарканде** или каллиграфическая эмблема, подпись честная («Imom al-Buxoriy yodgorlik majmuasi, Samarqand»). Предложи мне вариант и жди ответа.
- **Джалолиддин Мангуберди и аль-Хорезми.** Прижизненных изображений нет. Если на Commons найдётся только фото современного памятника — годится, но подпись должна говорить «памятник», а не «портрет». Если ничего свободного нет — оставь эмодзи-фолбэк и скажи мне, я закажу AI-иллюстрацию, как уже сделали для Темура.

## 3. Что сделать технически

1. Скачай выбранные изображения, оптимизируй: большая сторона ~800px, вес ≤ 300 КБ, формат webp (`sips` / ImageMagick / `cwebp` — чем есть). Новых npm-зависимостей не ставь.
2. Положи в `frontend/public/portretlar/<slug>.webp`, имя файла = slug героя из базы (возьми реальные slug из сид-миграций, не выдумывай).
3. Новая Flyway-миграция (следующим свободным номером): для каждого героя `UPDATE heroes SET portrait_url = '/portretlar/<slug>.webp', portrait_kind = '<PHOTO|MINIATURE|ARTWORK>', portrait_caption_uz = '<честная подпись на узбекском>', portrait_source = '<автор/музей + лицензия + Wikimedia Commons>' WHERE slug = '<slug>'`.
   - Пример подписи для миниатюры: `Zafarnoma qo'lyozmasidan miniatyura, 1467-yil`.
   - Пример для фото: `Fotosurat, XX asr boshi`.
   - Пример для памятника: `Urganchdagi haykal, zamonaviy`.
   - В `portrait_source` **обязательно** укажи лицензию и что источник — Wikimedia Commons; для CC BY-SA добавь автора.
4. Уже подключённый портрет Амира Темура (AI-иллюстрация) **не трогай**, если он на месте — только проверь, что подпись честная.
5. Убедись, что галерея и страница героя показывают изображение в золотом кольце медальона без сдвига вёрстки: фиксированные размеры, `loading="lazy"`, осмысленный `alt` («<Ism> portreti»), и остаётся эмодзи-фолбэк, если файла нет.

## 4. Правила

- Никакого «похожего» и «примерно того же» — если не уверен, что изображение действительно этого человека, не бери и скажи мне.
- Не брать изображения из поиска картинок, со стоков и с сайтов без лицензии — только Wikimedia Commons и подобные свободные хранилища.
- Ничего не менять в логике героев, диалогов и квизов — только изображения и подписи.
- Узбекская латиница во всех подписях; правила производительности из README (все десять картинок вместе не должны утяжелить галерею — проверь суммарный вес).
- README: строка о том, что портреты — из открытых источников с указанием лицензии.

## 5. Приёмка

1. `mvn test`, `npm run build && npm run lint` — зелёные.
2. У каждого из десяти героев либо корректное изображение с честной подписью и лицензией, либо эмодзи-фолбэк и объяснение, почему изображения нет.
3. Ни одно изображение не подписано как «портрет», если это памятник, миниатюра или современная иллюстрация.
4. Суммарный вес папки `public/portretlar/` разумный (ориентир — не больше 2–3 МБ на все портреты).
5. Галерея не «прыгает» при загрузке, на мобильной ширине всё читается.
