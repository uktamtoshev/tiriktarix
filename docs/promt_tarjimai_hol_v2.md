# Промт для Claude Code — страница биографии: сбор материала из интернета + подсветка карточки (v2)

> Скопируй всё, что ниже разделителя, в Claude Code в корне репозитория TIRIK TARIX. Это версия 2: биографию теперь разрешено собирать из проверенных интернет-источников, а не только из базы.

---

Кнопка «Batafsil» на карточках фактов открывает **отдельную страницу биографии**: `/qahramonlar/<slug>/tarjimai-hol` для человека и `/davrlar/<code>` для эпохи. На эту страницу нужно **собрать настоящий биографический материал из интернета** — но по строгим правилам, потому что продукт стоит на достоверности.

## 1. Сбор материала (WebSearch + WebFetch)

Для каждого предка собери связную биографию на узбекском: детство и происхождение, учёба, главные дела и труды, эпоха и окружение, наследие. Объём — примерно 300–500 слов, языком, понятным школьнику 10–14 лет.

**Разрешённые источники** (в порядке приоритета):

1. «O'zbekiston milliy ensiklopediyasi» и школьные учебники «O'zbekiston tarixi» — главный ориентир, продукт живёт по школьной программе.
2. Ziyouz.uz, сайты УзАН и государственных музеев, UNESCO.
3. Britannica, сайты университетов и научных институтов.
4. Википедия — **только как подсказка, где искать**; ссылаться на неё как на источник нельзя.

**Запрещено:** блоги, соцсети, реферат-сайты, «интересные факты», сайты без автора и даты, любые тексты, сгенерированные ИИ.

**Правила работы с фактами:**

- Каждый абзац биографии должен опираться на конкретный источник, и этот источник указывается на странице. Абзац без источника не публикуется.
- Каждую дату, число и имя проверяй **минимум по двум независимым источникам**. Если данные расходятся (например, разные годы рождения) — бери версию школьного учебника и добавь пометку, что в источниках есть расхождение.
- Ничего не пиши по памяти. Если факт не нашёлся в разрешённых источниках — не включай его вообще.
- Никаких легенд и преданий под видом фактов. Если сюжет известен как предание — так и подпиши: «rivoyatga ko'ra».
- Тон нейтральный, светский, для детей: без пафоса, без религиозной и политической оценки, без сцен жестокости.

## 2. Куда сохранять материал

Не хардкодь тексты в компонентах. Добавь данные в базу:

- Новая Flyway-миграция (следующим свободным номером): в таблицу `heroes` — колонки `biography_uz TEXT` и `biography_sources JSONB` (список источников: название + ссылка + что именно из него взято); флаг `biography_verified BOOLEAN NOT NULL DEFAULT FALSE`.
- Тем же способом для эпох (`eras`), если делаешь страницу эпохи.
- Тексты вставляй той же миграцией, `biography_verified = FALSE` — **методист-историк должен всё вычитать перед публикацией**. На странице, пока `false`, показывай сдержанную пометку внизу: «Matn metodist tekshiruvidan o'tmoqda».

## 3. Что на странице

1. **Шапка:** портрет в золотом медальоне с честной подписью, имя, звание, годы жизни, эпоха.
2. **«Tarjimai hol»** — собранная биография, разбитая на смысловые части с подзаголовками (Bolalik, Ta'lim, Asosiy ishlari, Merosi — по ситуации).
3. **«Hayot yo'li»** — вертикальная лента фактов этого героя из `fact_cards` (они уже проверены), у каждого источник; годы слева как метки, сортировка по годам.
4. **«U yashagan davr»** — события из `historical_events`, попавшие в годы его жизни (или его эпохи). Показывает, что происходило вокруг, пока он жил.
5. **«Bilimingni sinab ko'r»** — микро-квиз героя и фильм о нём из Кинозала, если есть.
6. **«Manbalar»** — полный список источников страницы со ссылками, без дублей.

**Подсветка карточки.** Кнопка «Batafsil» передаёт id карточки (`?card=<id>`): страница прокручивается к этому факту в ленте «Hayot yo'li» и подсвечивает его золотой рамкой на пару секунд. Так ребёнок понимает, что попал именно туда, откуда нажал.

## 4. Оформление

Стиль существующий: тёмный камень — фон страницы, **пергамент — блоки для чтения** (биография, факты), золотая инкрустация. Компоненты только из UI-кита (`Panel`, `SectionTitle`, `CornerFrame`, `HeroMedallion`, `Badge`, `Button`). Лента «Hayot yo'li» — вертикальная линия с золотыми точками-годами. Мобильные: одна колонка, крупный текст, кнопки от 44px. Контраст AA, `prefers-reduced-motion` уважается, анимации — существующие `tt-reveal`/`tt-rise`.

## 5. Правила

- Весь текст на странице — узбекская латиница.
- Сначала проверь существующие эндпоинты (`/api/heroes/{slug}`, `/api/library/factcards`, `/api/events`, `/api/films`); новый эндпоинт добавляй, только если реально не хватает.
- Ничего не ломать: библиотека и фильтры, страница героя, чат, квизы, Кинозал.
- Новых npm-зависимостей нет; правила производительности из README соблюдены.
- README: абзац про страницы биографии, откуда берётся текст и что он ждёт проверки методистом.

## 6. Приёмка

1. `mvn test`, `npm run build && npm run lint` — зелёные.
2. Клик «Batafsil» на карточке о рождении Беруни открывает его страницу биографии, прокручивает к этому факту и подсвечивает его.
3. Биография читается связно, разбита на части, у каждой части указан источник; внизу — полный список источников со ссылками.
4. Ни одной даты или числа без источника; расхождения в источниках помечены.
5. Пометка «Matn metodist tekshiruvidan o'tmoqda» видна, пока `biography_verified = false`.
6. Страница эпохи работает так же; у героя с малым материалом страница просто короче, но не сломана.
7. На телефоне всё читается, ничего не «прыгает».

В конце — таблица: герой, объём биографии, использованные источники (со ссылками), где были расхождения в данных, и что именно нужно вычитать методисту в первую очередь.
