# Промт для Claude Code — кнопка «Batafsil» на карточках фактов + страница биографии

> Скопируй всё, что ниже разделителя, в Claude Code в корне репозитория TIRIK TARIX.

---

Добавь на **каждую карточку факта** кнопку «Batafsil» («узнать больше»). По нажатию пользователь попадает на страницу с расширенной информацией о предке — прежде всего о его биографии. Кнопка должна появиться на всех карточках, во всех местах, где они показываются (библиотека, страница героя, режим флеш-карточек, если он уже сделан).

## 1. Куда ведёт кнопка

Карточки бывают двух видов, и вести они должны по-разному:

- **Карточка привязана к герою** (`hero_id` заполнен) → кнопка «Batafsil» ведёт на страницу этого героя `/qahramonlar/<slug>`, с якорем на блок биографии (например `#tarjimai-hol`), чтобы человек сразу попал в нужное место, а не в начало страницы.
- **Карточка привязана к эпохе** (`era_id`, героя нет) → кнопка ведёт на ленту событий этой эпохи (`/voqealar` с выбранной эпохой). Подпись тогда — «Davrni ko'rish».
- Если у карточки нет ни героя, ни эпохи — кнопку не показывай вообще, а не рисуй неактивной.

## 2. Блок биографии на странице героя

Проверь, есть ли на странице героя развёрнутая биография. Если её нет или она в одну строку — собери блок **«Tarjimai hol»** так:

1. Сверху — текст `bio_uz` из базы (он уже есть у героев).
2. Под ним — **лента фактов этого героя из `fact_cards`**, отсортированная по смыслу/хронологии, каждый факт с указанием источника, как на карточке.
3. Заголовок блока, якорь `id="tarjimai-hol"`, оформление — существующие `Panel` / `SectionTitle` / пергаментные стили проекта.

**Крайне важно:** никакого нового биографического текста от себя. Не пиши факты из своих знаний, не пересказывай Википедию. Биография собирается **только** из уже проверенных данных в базе (`bio_uz` + карточки фактов с источниками) — это принцип достоверности №1 проекта. Если материала мало, так и оставь и скажи мне: я добавлю карточки через конвейер фактов (`docs/promt_fakt_konveyer.md`).

## 3. Как должна выглядеть кнопка

- Текст: **«Batafsil»** (для карточек эпохи — «Davrni ko'rish»), рядом стрелка «→» в стиле кнопки «Suhbatni boshlash» на карточках героев — чтобы вся система выглядела единообразно.
- Место: внизу карточки, под строкой источника, выровнена вправо; на пергаментной карточке — тёмным по пергаменту, чтобы контраст был AA.
- Это ссылка (`<a>` / `Link`), а не кнопка с onClick: должна открываться в новой вкладке по Cmd/Ctrl+клик и быть видна поисковикам.
- Доступность: `aria-label` вида «Abu Rayhon Beruniy haqida batafsil», фокус-кольцо по правилам проекта, высота касания не меньше 44px на мобильных.
- Ничего не должно «прыгать»: кнопка не меняет высоту карточки при наведении.

## 4. Правила

- Используй существующие компоненты UI-кита (`Button` с нужным вариантом или ссылку в его стиле) — новых компонентов не плоди.
- Бэкенд трогать не нужно: `heroSlug`/`eraCode` уже приходят или выводятся из `heroId`/`eraId`; если на фронте не хватает slug героя — возьми его из уже загруженного списка героев, новых эндпоинтов не создавай.
- Весь текст — узбекская латиница.
- Ничего не сломать: фильтры библиотеки, страницы героев, чат, квизы.
- README: одна строка про кнопку «Batafsil» и блок биографии.

## 5. Приёмка

1. `npm run build && npm run lint` — зелёные (и `mvn test`, если бэкенд всё же тронут).
2. На карточке Беруни (и на любой другой карточке героя) внизу есть «Batafsil», клик ведёт на страницу героя и сразу к блоку «Tarjimai hol».
3. На карточке эпохи кнопка называется «Davrni ko'rish» и ведёт к событиям нужной эпохи.
4. У карточки без героя и эпохи кнопки нет.
5. Блок биографии собран только из `bio_uz` и карточек фактов, у каждого факта виден источник; выдуманного текста нет.
6. Карточки не изменили высоту/вёрстку, контраст кнопки на пергаменте проходит AA.
