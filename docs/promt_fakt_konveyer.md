# Промт для Claude Code — конвейер проверки фактов от участников команды

> Скопируй всё, что ниже разделителя, в Claude Code в корне репозитория TIRIK TARIX.

---

Настрой конвейер приёма фактов от участников команды: они собирают факты в простой файл, ты **перепроверяешь каждый факт и превращаешь проверенные в карточки `fact_cards`**. Ничего в существующих карточках не менять.

## 1. Файл-приёмник

Создай `docs/fakty_inbox.md` с шаблоном и примером — участники будут заполнять его руками:

```
| тема (uz) | факт (uz, 1-3 предложения) | источник (книга + страница) | герой (slug) или эпоха (code) |
```

В шапке файла — короткая инструкция для участников на русском: факт только из учебника/энциклопедии, обязательно страница источника, без выдумок и без «где-то читал».

## 2. Проверка (каждый запуск)

Когда я скажу «проверь факты», ты:

1. Читаешь `docs/fakty_inbox.md`.
2. Для каждого факта проверяешь: формат заполнен полностью; герой/эпоха существуют в сиде (реальные slug/code — посмотри в миграциях); **нет дубликата** среди существующих `fact_cards` (сравни по теме и смыслу); правдоподобность — сверь через WebSearch с авторитетными источниками (энциклопедии, музеи, академические сайты). Даты, имена, числа — проверять особенно строго.
3. Каждому факту ставишь вердикт: ✅ принят / ⚠️ сомнение (что именно смущает) / ❌ отклонён (причина).
4. Показываешь мне таблицу вердиктов и **ждёшь моего «ок»**.

## 3. После моего одобрения

- Новая Flyway-миграция (следующий свободный номер): `INSERT INTO fact_cards (hero_id/era_id, topic_uz, fact_uz, keywords, source, verified)` — только принятые факты. `verified = FALSE` — финальную проверку делает методист-историк, ИИ-проверка её не заменяет.
- `keywords` (jsonb) сгенерируй сам по правилам существующих карточек (посмотри, как заполнены в сиде — они питают поиск диалогового движка).
- Проверенные строки перенеси из inbox в `docs/fakty_qabul.md` (архив принятых, с датой и именем участника), отклонённые — оставь в inbox с пометкой причины.
- `mvn test` зелёный; существующие карточки не изменились (проверь count до/после — прирост ровно на число принятых).

## 4. Правила

- Ты — вторая линия проверки, не первая: если источник не указан — факт не проверяешь, а сразу возвращаешь участнику.
- Никогда не «дочиняй» факт сам — можно только исправить орфографию узбекского текста, смысл не трогать.
- Спорная тема (политика, религия) — вердикт «⚠️ методисту», в базу не вносить даже после моего «ок».
- В сводке каждого запуска: сколько принято/отклонено/на методиста, у кого из участников лучший процент принятых (мотивация команды!).
