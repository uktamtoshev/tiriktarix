# Промт для Claude Code — флеш-карточки в разделе «Xazina» (библиотека)

> Скопируй всё, что ниже разделителя, в Claude Code в корне репозитория TIRIK TARIX. Скриншот с точным местом кнопки я приложу отдельно.

---

Добавь в раздел библиотеки («Xazina», страница `frontend/src/app/(shell)/kutubxona/page.tsx`) режим **флеш-карточек** — карточек для заучивания, у которых две стороны: спереди вопрос, сзади ответ; по клику карточка переворачивается. Точное место кнопки я покажу скриншотом — если скриншота нет, спроси меня, не выбирай сам.

## 1. Что должно получиться

**Кнопка «Flesh-kartalar»** на странице библиотеки. По нажатию открывается выбор из двух вариантов:

- **«O'zim yarataman»** — пользователь создаёт карточки сам.
- **«Kutubxonadan olish»** — карточки берутся из существующих карточек фактов.

Дальше — режим тренировки: одна карточка на экране, кнопка перевернуть, переход к следующей, перемешать колоду.

### Вариант «Kutubxonadan olish»

- Показывается список/сетка всех карточек фактов из библиотеки (эндпоинт `GET /api/library/factcards` уже есть, фильтры по герою и эпохе на странице тоже) — пользователь отмечает нужные или берёт всё разом кнопкой «Hammasini olish».
- Сопоставление сторон: **лицевая сторона — `topic_uz`** (тема как вопрос, подпись сверху «Bu haqda nima bilasan?»), **обратная — `fact_uz` + источник `source`** мелким шрифтом. Источник обязателен: это принцип №1 проекта, факт без источника не показываем.
- Уважай текущие фильтры страницы: если выбран герой или эпоха — «Hammasini olish» берёт только отфильтрованные карточки.

### Вариант «O'zim yarataman»

- Простая форма: два поля — **«Savol»** (лицевая) и **«Javob»** (обратная), кнопка «Qo'shish». Добавленная карточка сразу появляется в колоде.
- Свои карточки хранятся в **localStorage** по ключу вроде `tirik-tarix-flashcards` (привязка к `getClientId()`), без бэкенда и без миграций — так работает и для гостя, и офлайн. Предупреди пользователя одной строкой, что свои карточки хранятся в этом браузере.
- Можно удалить свою карточку. Редактирование не нужно.

### Режим тренировки

- Одна карточка по центру, крупно. Кнопка **«Javobni ko'rish»** или клик по самой карточке — переворот; после переворота кнопка становится **«Savolni ko'rish»**.
- Навигация: «Keyingisi» / «Oldingisi», счётчик «3 / 12», кнопка «Aralashtirish» (перемешать).
- Клавиатура: пробел — перевернуть, стрелки — вперёд/назад. Фокус-кольца по правилам проекта, `aria-live` для смены карточки, у карточки понятный `aria-label`.
- Выход из режима — кнопка «Chiqish», возвращает к обычному виду библиотеки.

## 2. Дизайн (важно, это фишка)

Переворот делай в духе TEMIR VA ZAR, используя уже существующую метафору проекта: **лицевая сторона — стальная плашка** (как вопрос ученика в чате героя), **обратная — пергамент** (как ответ предка). Получится визуально та же логика «спрашиваю → отвечает история», которая уже есть в диалогах.

- Переворот — CSS 3D (`transform: rotateY(180deg)`, `backface-visibility: hidden`), без новых npm-зависимостей.
- Уважай `prefers-reduced-motion`: при `reduce` карточка меняет сторону без анимации, мгновенно.
- Угловые орнаменты (`CornerFrame`) и золотая окантовка — как у существующих панелей; используй `Panel`, `Button`, `Badge`, `FilterChip` из UI-кита, не изобретай новые компоненты.
- Мобильные: карточка на всю ширину, крупный текст, кнопки не меньше 44px по высоте.

## 3. Правила

- Весь UI-текст — узбекская латиница. Названия кнопок: «Flesh-kartalar», «O'zim yarataman», «Kutubxonadan olish», «Javobni ko'rish», «Keyingisi», «Aralashtirish», «Chiqish».
- Ничего не ломать: обычный вид библиотеки, фильтры, остальные страницы. Флеш-карточки — надстройка над существующей страницей, а не новая логика библиотеки.
- Бэкенд не трогать вообще: новых эндпоинтов, таблиц и миграций не нужно.
- Новых npm-зависимостей не добавлять; правила производительности из README (слабые телефоны) соблюдать.
- Обнови README: пара строк про флеш-карточки в описании библиотеки.

## 4. Один вопрос, который надо задать мне до начала

В проекте уже может быть страница экипировки персонажа с названием **«Xazina»** (из промта про персонажа). Если библиотека тоже называется «Xazina» — это конфликт названий. Проверь и **скажи мне**, не переименовывай сам: я решу, какой раздел переименовать.

## 5. Приёмка

1. `npm run build && npm run lint` — зелёные.
2. Кнопка «Flesh-kartalar» на месте (по моему скриншоту), по нажатию — два варианта.
3. «Kutubxonadan olish»: показываются карточки библиотеки с учётом фильтров, можно выбрать нужные или взять все; в тренировке спереди тема, сзади факт с источником.
4. «O'zim yarataman»: карточка добавляется, появляется в колоде, переживает перезагрузку страницы, удаляется по кнопке.
5. Переворот работает кликом, пробелом и кнопкой; стрелки листают; «Aralashtirish» меняет порядок.
6. При `prefers-reduced-motion: reduce` анимации нет, функциональность цела.
7. Обычная библиотека и её фильтры работают как раньше.

В конце — сводка: изменённые файлы, где лежит логика хранения своих карточек, и 30-секундный сценарий проверки руками.
