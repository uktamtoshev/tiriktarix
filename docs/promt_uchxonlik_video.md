Найди в интернете обучающее видео/фильм **для детей и подростков** про три ханства (Бухара, Хива, Коканд) и прикрепи его к карточке «Uch xonlik: bir yurt, uch davlat» в Кинозале. Только эта одна карточка. Схема — та же, что для предыдущих карточек (`docs/promt_avesto_video.md`): два этапа, реализация только после моего одобрения. Уже реализованные превью/модал-плеер переиспользуй без изменений.

## 0. Контекст

- Карточка в `backend/src/main/resources/db/migration/V8__films.sql`: эпизод «Uch xonlik: bir yurt, uch davlat» (SHORT, ~4 daq., сейчас без видео). Суть темы: Бухарский эмират, Хивинское и Кокандское ханства — почему единая земля разделилась на три государства и к чему это привело.
- Новую миграцию создавай следующим свободным номером в `db/migration/`.

## Этап 1 — Поиск (WebSearch + WebFetch)

Платформы: YouTube, Mover.uz, Vimeo, Dailymotion, Rutube, каналы узбекских ТВ и образовательных проектов. Формулировки:

- узбекский: «uch xonlik tarixi hujjatli film», «Buxoro amirligi tarixi video», «Xiva xonligi tarixi hujjatli», «Qo'qon xonligi tarixi», «xonliklar davri O'zbekiston tarixi»
- русский: «три ханства Средней Азии документальный фильм», «Бухарский эмират Хивинское ханство Кокандское ханство история», «среднеазиатские ханства фильм»

Критерии (все обязательны):

1. Образовательное: документалка/лекция/анимация об истории — причины раздробленности, устройство трёх государств, последствия.
2. **Нейтральный исторический тон**: тема граничит с политически чувствительными сюжетами (раздробленность, позднее колониальное завоевание) — никаких видео с современными политическими оценками, национализмом или пропагандой. Только спокойная история для детского продукта.
3. Подходит детям/подросткам; если для старших — пометь.
4. Не Shorts и не клип: ≥ 3 минут, URL без `/shorts/`.
5. **Оригинальный канал, не пиратский перезалив** — у фильмов телеканалов ищи официальный канал.
6. Язык: узбекский приоритетен, русский с пометкой «RU».
7. **Каждая ссылка верифицирована WebFetch'ем**: заголовок, канал, длительность, доступность. Ссылки «из памяти» запрещены; непроверяемая = отклонена.

Результат — таблица топ-3: `платформа | название | канал | язык | длительность | возраст | URL | плюсы/минусы`, рекомендация №1, отклонённые с причинами. **Жди моего «ок»**.

## Этап 2 — Реализация (после одобрения)

- Миграция: `UPDATE films SET video_url = '…', status = 'PUBLISHED', duration_minutes = <фактическая>, source = '<Платформа>: <канал>'` только для этой карточки; `verified = false` (методист отсмотрит).
- Список `/filmlar`: превью-кадр + запуск (YouTube → модал `youtube-nocookie`, iframe только после клика; иная платформа → внешняя ссылка с бейджем, `rel="noopener"`).
- Детальная карточка: блок просмотра «Ko'rish» с атрибуцией канала; шаг 4 конвейера для внешнего видео — честная подпись «Video biriktirildi (tashqi manba)».
- UI-текст — узбекская латиница.

## Ограничения и приёмка

- Трогать только эту карточку; схему `films`, старые миграции, остальные эпизоды не менять; зависимостей не добавлять.
- Приёмка: таблица до реализации; ссылка открывается и совпадает по заголовку; `mvn test`, `npm run build && npm run lint` зелёные; карточка «Uch xonlik» играет видео, остальные без изменений; в сводке — платформа, язык, возраст, напоминание методисту (verified=false).
