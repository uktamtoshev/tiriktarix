# Промт для Claude Code — расширить галерею предков: 50 кандидатов → мой выбор → добавление

> Скопируй всё, что ниже разделителя, в Claude Code в корне репозитория TIRIK TARIX.

---

Нужно добавить в проект новых предков — тех, с кем ребёнок сможет поговорить в «Ajdodlar zali». Работа в два этапа: **сначала ты предлагаешь 50 кандидатов и ждёшь моего выбора**, потом добавляешь только выбранных. Ничего не добавляй до моего ответа.

## Этап 1 — 50 кандидатов (только список, без кода)

Изучи, кто уже есть в базе (`heroes` в сид-миграциях), и предложи **50 новых** исторических личностей, связанных с историей Узбекистана и Центральной Азии.

**Требования к списку:**

- **Покрытие всех восьми эпох** проекта (`eras`), а не только Темуридов. Минимум по 4 кандидата на каждую эпоху.
- **Обязательно женщины** — не меньше 10 из 50. Сейчас в проекте одни мужчины, а половина аудитории — девочки. Смотри в сторону правительниц, поэтесс, просветительниц, учёных.
- Разные роли, а не только правители и полководцы: учёные, врачи, поэты, математики, астрономы, зодчие, путешественники, музыканты, просветители, первые учительницы.
- Люди, интересные ребёнку 10–14 лет: у каждого должна быть история, которую можно рассказать.

**Формат таблицы** (по одной строке на кандидата, сгруппировать по эпохам):

`Имя (uz) | годы жизни | эпоха (code) | кто это в одном предложении | чем зацепит ребёнка | есть ли свободное изображение (PD/CC на Wikimedia) — да/нет/памятник | насколько легко найти проверенные факты (легко/средне/трудно)`

Две последние колонки критичны: герой без фактов не сможет разговаривать, а без изображения будет с эмодзи вместо портрета. Оцени их честно, проверив поиском, а не на глаз.

Внизу таблицы напиши: сколько фактов и вопросов теста придётся написать на одного героя и **сколько всего работы выйдет**, если я выберу 10, 20 или 30 — чтобы я понимал цену решения.

Покажи таблицу и **жди моего ответа**. Я отмечу, кого добавляем.

## Этап 2 — Добавление выбранных (после моего «ок»)

Для **каждого** выбранного героя собери и внеси полный комплект, иначе он окажется в галерее «немым»:

1. **Запись в `heroes`:** `slug` (латиница, kebab-case), `name_uz`, `title_uz`, `birth_year`, `death_year`, `era_id` (по code эпохи), `bio_uz` (3–5 предложений для ребёнка), `greeting_uz` (как он здоровается в диалоге, от первого лица), `portrait_emoji`, `on_topic_keywords` (jsonb — слова, по которым движок понимает, что вопрос о нём: имя, город, труды, ключевые темы).
2. **8–10 карточек фактов** в `fact_cards` с `hero_id`, у каждой: `topic_uz`, `fact_uz` (от первого лица, как говорит сам предок — посмотри, как написаны карточки Темура), `keywords`, `source` — **обязательно реальный источник**, `verified = FALSE`.
3. **10 вопросов** в `quiz_questions` с `hero_id`: `question_uz`, 4 варианта в `options`, `correct_index`, `explanation_uz`. Вопросы строй **только по написанным карточкам фактов**, чтобы ребёнок мог найти ответ в продукте.
4. **Портрет**, если нашёлся свободный: скачай, оптимизируй (≤300 КБ, webp, ~800px), положи в `frontend/public/portretlar/<slug>.webp`, заполни `portrait_url`, `portrait_kind`, `portrait_caption_uz`, `portrait_source` с лицензией. Если свободного нет — оставь эмодзи и напиши мне об этом.

Всё — одной новой Flyway-миграцией со следующим свободным номером (или несколькими, если объём большой), старые миграции не трогать.

## Источники и достоверность

- Разрешено: «O'zbekiston milliy ensiklopediyasi», школьные учебники «O'zbekiston tarixi», Ziyouz.uz, сайты музеев и УзАН, UNESCO, Britannica, сайты университетов. Википедия — только как подсказка, куда смотреть, ссылаться на неё нельзя.
- Каждую дату и число проверяй по двум источникам; расхождения — бери версию учебника и пометь.
- **Ничего по памяти.** Не нашёл в разрешённых источниках — не пиши.
- Легенды подписывай как легенды («rivoyatga ko'ra»), фактами их не выдавай.
- Тон нейтральный, светский, детский: без пафоса, без религиозной и политической оценки, без жестокости.
- Всё новое — `verified = FALSE`: методист-историк вычитывает перед публикацией.

## Правила

- Весь контент — узбекская латиница.
- Не ломать существующих героев, их карточки, вопросы и диалоги; slug'и новых героев не должны конфликтовать со старыми.
- Проверь, что новые герои корректно появляются в галерее, открывают диалог, микро-квиз работает, а движок диалога находит их карточки по ключевым словам.
- Новых npm-зависимостей нет; правила производительности из README (галерея не должна тяжелеть — портреты оптимизированы).

## Приёмка

1. `mvn test`, `npm run build && npm run lint` — зелёные.
2. Каждый новый герой: есть в галерее, здоровается, отвечает по своим карточкам, отказывается по правилам («Bu haqda tarix sukut saqlaydi» / «Iltimos, men haqimda savol ber»), имеет работающий микро-квиз из 10 вопросов.
3. У каждой карточки факта указан реальный источник; выдуманных фактов нет.
4. Эпохи покрыты равномернее, чем раньше; женщины в галерее есть.
5. Старые герои и их контент не изменились (проверь количество записей до и после).

В конце — таблица: герой, эпоха, сколько карточек и вопросов добавлено, есть ли портрет и с какой лицензией, где были расхождения в источниках, что в первую очередь вычитать методисту.
