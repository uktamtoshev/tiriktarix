## Этап 1 — Поиск по всей сети (WebSearch + WebFetch)

Ищи не только на YouTube, но и на похожих платформах: **Mover.uz** (узбекский видеохостинг), Vimeo, Dailymotion, Rutube, каналы узбекских ТВ и образовательных проектов. Запросы пробуй в нескольких формулировках и языках:

- узбекский: «Avesto haqida hujjatli film», «Avesto qadimgi Xorazm video», «zardushtiylik tarixi bolalar uchun», «Avesto kitobi tarixi»
- русский: «Авеста документальный фильм для детей», «зороастризм древний Хорезм фильм», «Авеста памятник письменности видео»

Критерии (все обязательны):

1. Образовательное: документалка, лекция, анимация — исторический ракурс (Авеста как древнейший письменный памятник, родина — древний Хорезм). **Не религиозная проповедь** — продукт светский, детский.
2. Подходит детям/подросткам: без жестокости и взрослого контента; если видео скорее для старших подростков — пометь это в таблице.
3. Не Shorts и не клип: длительность ≥ 3 минут, URL без `/shorts/`.
4. Язык: узбекский приоритетен, русский допустим (с пометкой «RU»).
5. **Ссылка верифицирована WebFetch'ем страницы**: реальный заголовок, канал/автор, длительность, видео доступно. Ссылки «из памяти» запрещены — только найденные сейчас. Непроверяемая ссылка = кандидат отклонён.

Результат этапа — таблица топ-3 кандидатов: `платформа | название | канал | язык | длительность | для какого возраста | URL | плюсы/минусы`, твоя рекомендация №1 и список отклонённого с причинами. **Жди моего «ок»**.

## Этап 2 — Реализация (после одобрения)

- Миграция: `UPDATE films SET video_url = '…', status = 'PUBLISHED', duration_minutes = <фактическая>, source = '<Платформа>: <канал>'` для этой карточки. `verified` оставь `false` — методист должен отсмотреть. Constraint `films_published_needs_video` соблюдается сам.
- Отображение:
  - YouTube → превью-кадр `i.ytimg.com/vi/{id}/hqdefault.jpg` (lazy `<img>`), клик → модал с `youtube-nocookie.com/embed/{id}?rel=0`, iframe грузится только после клика (facade-паттерн), + кнопка «YouTube'da ochish».
  - Другая платформа → без встроенного плеера: карточка с бейджем платформы («Mover.uz», «Vimeo»…) открывает видео в новой вкладке (`rel="noopener"`). Новых плееров и npm-зависимостей не городить.
- UI-текст — узбекская латиница («Ko'rish», «Tashqi manba»). Атрибуция канала на карточке обязательна.

## Ограничения
