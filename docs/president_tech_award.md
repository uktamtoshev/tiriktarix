# TIRIK TARIX — материалы для President Tech Award

Заготовка заявки: готовые формулировки, которые можно переносить в форму на
[awards.gov.uz](https://awards.gov.uz), в презентацию и в питч.

**Состояние на 7 августа 2026.** Все цифры проверяемы: они взяты из работающей
базы и исходников проекта, а не из планов.

---

## 1. Резюме (30 секунд)

**TIRIK TARIX** — бесплатная образовательная платформа, на которой дети
Узбекистана изучают историю страны, разговаривая с историческими личностями на
узбекском языке. Ребёнок открывает «Зал предков», выбирает Амира Темура и
спрашивает своими словами — герой отвечает от первого лица, а под ответом стоит
источник.

Главное отличие от развлекательных ИИ-чатов: **герой физически не может
выдумать факт.** Он отвечает только по карточкам, проверенным
методистом-историком, а там, где история молчит, честно говорит:
«Bu haqda tarix sukut saqlaydi».

Это **не прототип**: работают 55 личностей, 962 карточки фактов с источниками,
1 227 вопросов тестов, 8 эпох, админ-панель для историка и озвучка на узбекском.

## 2. Автор

Мираброр, 11 лет. Школьник. Проект задуман и доведён до работающего продукта им
самим.

Первой школой-пилотом станет его собственная.

## 3. Проблема

1. История Узбекистана — обязательный школьный предмет: её изучают **более 6 млн
   школьников**, около **1 млн абитуриентов** сдают её на вступительных.
2. Доминирующий формат — заучивание дат и параграфов. Знания не удерживаются,
   интерес к предмету низкий.
3. Увлекательного цифрового контента об истории **на узбекском языке практически
   нет** — ниша пуста.
4. Если ребёнок спросит у обычного чат-бота — тот уверенно выдумает. Детям так
   нельзя: выдуманный факт об истории собственной страны хуже, чем отсутствие
   ответа.
5. Платные образовательные сервисы недоступны значительной части семей.

Иллюстрация, с которой начинается питч: слово «алгоритм» — это имя нашего
земляка, аль-Хорезми. Его произносит каждый программист мира каждый день, а наши
школьники о нём почти ничего не знают.

---

## 4. Решение

Платформа из связанных модулей, где вся начинка растёт из одной проверенной базы
фактов:

| Модуль | Что делает | Состояние |
|---|---|---|
| **Зал предков** | Разговор с исторической личностью, микро-квиз, загадка дня, биография с источниками | Работает |
| **События и карты** | Лента времени и интерактивные исторические карты по эпохам | Работает |
| **Сынов (тесты)** | Тесты по эпохам, разбор ошибок со ссылкой на факт, флеш-карточки, дуэли учеников | Работает |
| **Кинозал** | Документальные ролики по эпохам с тестом после просмотра | Работает |
| **Хазина (библиотека)** | Карточки фактов с раскрытием и источником | Минимум готов |
| **Мультфильмы** | ИИ-анимация по утверждённым сценариям | Фаза 2 |
| **Кабинет учителя** | Прогресс класса, задания к уроку | Фаза 2 |

Плюс сквозная геймификация: XP, уровни и звания, серии, достижения, персонаж с
10 архетипами и 32 предметами экипировки, таблица лидеров, маскот-помощник.

## 5. Ключевое отличие — достоверность как инженерное решение

Формула проекта: **ИИ создаёт форму — за правду отвечают люди.**

Это не декларация, а архитектура:

1. Модель никогда не отвечает «из своих знаний» — в контекст подаются **только**
   карточки фактов данного героя, проверенные методистом.
2. **Два уровня отказа:** нет факта в карточке → «Об этом история умалчивает»;
   вопрос не по теме → «Задай вопрос обо мне».
3. **Граница смерти:** герой не знает ничего после года своей смерти. Поле
   обязательно на уровне валидации, иначе запись не сохранится.
4. У каждого факта показан источник — ziyouz.com, УзА, «Национальная
   энциклопедия Узбекистана», школьный учебник.
5. Историк правит контент сам через админ-панель, все правки пишутся в журнал
   аудита. Пока биография не подтверждена методистом, на странице висит «текст на
   проверке».

**Побочный эффект, важный для регионов:** если API-ключа или интернета нет,
движок автоматически откатывается на поиск по карточкам, и продукт продолжает
работать. Те же правила достоверности действуют в обоих режимах.

## 7. Технологии

- **Диалог:** Claude (Anthropic) в режиме RAG с жёстким контекстом карточек;
  автоматический откат на поиск по ключевым словам без API-ключа.
- **Бэкенд:** Java 17, Spring Boot 3.5, PostgreSQL 16, Flyway.
- **Фронтенд:** Next.js 16 (App Router), TypeScript, Tailwind CSS 4.
- **Голос:** синтез и распознавание узбекской речи (сейчас браузерное; подключение
  специализированного узбекского TTS/STT — задача фазы 1).
- **Безопасность детей:** работа без регистрации, минимизация персональных данных,
  настоящее имя нигде не публично, предупреждение в чате.

---

## 8. Социальная модель

**Ребёнок не платит никогда** — ни подписок, ни рекламы, ни платных героев.

Расходы (серверы, API, озвучка, методист, художник) покрываются извне:

1. **Грант President Tech Award** — фазы 0–1: разработка, контент, пилоты школ.
2. **Государственные программы** цифрового образования, партнёрство с органами
   народного образования — фаза 2, масштабирование на школы.
3. **CSR-спонсорство** (телеком, банки, IT): пакет «спонсор эпохи/героя» с
   публичным упоминанием — без влияния на контент.
4. **Международные образовательные гранты** — исследование эффекта.

Прозрачность: публичная смета и годовой отчёт о расходах.

Годовое содержание платформы — около **$8 000**. Проекту почти не нужны деньги на
технику: платформа работает на том, что уже есть у ребёнка в кармане.

## 10. Метрики успеха

**MVP:** ≥60% тестеров вернулись на 7-й день; средний микро-квиз ≥3,5/5; ≥90%
ответов героев без фактических ошибок по выборке методиста.

**Год 1:** 10 000 MAU; удержание D7 ≥25%; 3 школы-пилота (минимум одна не в
Ташкенте); NPS учителей ≥40; ≥30% пользователей проходят ≥1 тест в неделю; 100%
функций бесплатны.

## 12. Почему это заслуживает поддержки

1. **Работающий продукт, а не идея.** 55 личностей, 962 факта, 1 227 вопросов — в
   базе, а не в презентации.
2. **Ниша пуста.** Качественного цифрового контента об истории Узбекистана на
   узбекском языке практически нет.
3. **Решена главная проблема ИИ в образовании.** Не «мы постараемся, чтобы модель
   не врала», а архитектура, в которой она не может соврать.
4. **Национальная повестка.** Продукт полностью на государственном языке, о
   собственной истории, для собственных школ.
5. **Социальная модель.** Бесплатно для всех детей навсегда.
6. **Автору 11 лет.** Это ровно та история, ради которой существуют конкурсы
   поддержки молодых технологов.
