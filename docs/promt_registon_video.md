Найди в интернете обучающее видео/фильм **для детей и подростков** о том, как построен ансамбль Регистан, и прикрепи его к карточке «Registon qanday qurilgan» в Кинозале. Только эта одна карточка. Схема — та же, что для «Avesto», «Ipak yo'li» и «Buxoro» (`docs/promt_avesto_video.md`): два этапа, реализация только после моего одобрения. Уже реализованные превью/модал-плеер переиспользуй без изменений.

## 0. Контекст

- Карточка в `backend/src/main/resources/db/migration/V8__films.sql`: эпизод «Registon qanday qurilgan» (HUJJATLI, ~6 daq., сейчас без видео). Суть темы: ансамбль в центре Самарканда — три медресе (Улугбека, 1417–1420; Шердор; Тилля-Кари), кто и когда их построил, что означают орнаменты и узоры.
- Новую миграцию создавай следующим свободным номером в `db/migration/`.

## Этап 1 — Поиск (WebSearch + WebFetch)

Платформы: YouTube, Mover.uz, Vimeo, Dailymotion, Rutube, каналы узбекских ТВ и образовательных проектов. Формулировки:

- узбекский: «Registon ansambli hujjatli film», «Registon qanday qurilgan», «Samarqand Registon tarixi video», «Ulug'bek madrasasi tarixi», «Sherdor Tillakori madrasa tarixi»
- русский: «Регистан Самарканд документальный фильм», «как строили Регистан», «медресе Улугбека Шердор Тилля-Кари история», «архитектура Регистана орнаменты»

Критерии (все обязательны):

1. Образовательное: документалка/анимация/лекция об истории и архитектуре — строители, эпохи, значение орнаментов. **Не тревел-влог с прогулкой и болтовнёй**: влог допусти́м только если он реально познавательный — тогда пометь это в таблице.
2. Светский ракурс: медресе — как исторические учебные заведения, акцент на архитектуру, науку и мастеров.
3. Подходит детям/подросткам; если для старших — пометь.
4. Не Shorts и не клип: ≥ 3 минут, URL без `/shorts/`.
5. **Оригинальный канал, не пиратский перезалив** — у фильмов телеканалов ищи официальный канал.
6. Язык: узбекский приоритетен, русский с пометкой «RU».
7. **Каждая ссылка верифицирована WebFetch'ем**: заголовок, канал, длительность, доступность. Ссылки «из памяти» запрещены; непроверяемая = отклонена.

Результат — таблица топ-3: `платформа | название | канал | язык | длительность | возраст | URL | плюсы/минусы`, рекомендация №1, отклонённые с причинами. **Жди моего «ок»**.

## Этап 2 — Реализация (после одобрения)

- Миграция: `UPDATE films SET video_url = '…', status = 'PUBLISHED', duration_minutes = <фактическая>, source = '<Платформа>: <канал>'` только для этой карточки; `verified = false` (методист отсмотрит).
- Список `/filmlar`: превью-кадр + запуск (YouTube → модал `youtube-nocookie`, iframe только после клика; иная платформа → внешняя ссылка с бейджем, `rel="noopener"`).
- Детальная карточка: блок просмотра «Ko'rish» с атрибуцией канала; шаг 4 конвейера для внешнего видео — честная подпись «Video biriktirildi (tashqi manba)».
- UI-текст — узбекская латиница.

## Ограничения и приёмка

- Трогать только эту карточку; схему `films`, старые миграции, остальные эпизоды не менять; зависимостей не добавлять.
- Приёмка: таблица до реализации; ссылка открывается и совпадает по заголовку; `mvn test`, `npm run build && npm run lint` зелёные; карточка «Registon» играет видео, остальные без изменений; в сводке — платформа, язык, возраст, напоминание методисту (verified=false).
