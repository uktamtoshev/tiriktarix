# Промт для Claude Code — Blender-фигуры по образцу текущих персонажей (v2)

> Скопируй всё, что ниже разделителя, в Claude Code в корне репозитория TIRIK TARIX. Это версия 2 — заменяет старый промт про Blender: типажи уже реализованы, теперь 3D-фигура должна повторять существующий стиль.

---

Страница «Qahramoning» с типажами уже работает: 5 мужских и 5 женских типажей, выбор пола, а в «Qurolxona» есть большое превью «Sening qahramoning» (32 предмета экипировки). Задача: сделать в Blender **3D-фигуры, которые повторяют силуэт и стиль текущих SVG-персонажей**, но с разным телосложением по типажу — воин крупный и мускулистый, обычный парень обычный. Выбранный на «Qahramoning» типаж показывается большой фигурой в «Qurolxona». Всё моделирование и рендер — скриптами через Blender Python API (`bpy`), без ручной работы и без чужих моделей.

Работай **этапами с остановками**: после тестового рендера покажи картинку и жди моего «ок».

## Этап 0 — Окружение

1. `blender --version` (на macOS обычно `/Applications/Blender.app/Contents/MacOS/Blender`). Нет Blender — скажи мне и остановись.
2. Проверь headless-запуск: `blender --background --python <тест>`.
3. Скрипты живут в `tools/blender/` — в сборку фронта не попадают.

## Этап 1 — Сначала изучи, как персонаж выглядит сейчас

Открой SVG-компоненты персонажа (Character и всё, что рисует типажи и предметы) и выпиши в `tools/blender/style.md`:

- точные цвета: кожа, волосы, одежда каждого типажа, кожаный доспех, щит, меч, фон;
- фирменные элементы, по которым персонаж узнаётся: повязка с золотыми ромбами, пучок волос у девушек, круглый щит с концентрическими кругами, форма меча, тиара малики и т.п.;
- пропорции **большого превью из Qurolxona** (вытянутая фигура, а не «чиби» с карточек выбора — чиби-карточки не трогаем, они остаются SVG).

3D-фигура должна читаться как **тот же самый герой, объёмный** — не новый дизайн. Простое лицо без мелких черт, плоские материалы без бликов, палитра проекта.

## Этап 2 — Процедурная фигура (и стоп на проверку)

`tools/blender/character.py`: низкополигональная стилизованная фигура, параметры — пол и телосложение (ширина плеч, обхват груди, талия, толщина рук/ног, рост).

Телосложение жёстко привязано к типажу:

| Типаж | Телосложение |
|---|---|
| jangchi, sarkarda | muscular — широкие плечи, крупные руки, мощная грудь |
| ko'chmanchi, jangchi-qiz, ko'chmanchi-qiz | athletic — жилистый, подтянутый |
| amirzoda, malika, olima | slim — стройный, прямая осанка |
| oddiy-yigit, oddiy-qiz | average — обычный, ничего выдающегося |

Женские фигуры отличаются пропорциями (плечи уже, рост чуть ниже), одежда и волосы — отдельными объектами. Итого **10 базовых фигур** — по одной на типаж.

Рендер-движок — EEVEE или Workbench с плоской заливкой, ортографическая камера, низкие сэмплы: рендер должен занимать секунды даже на ноутбуке с Intel.

**Тестовый рендер:** malika, поза как в текущем превью, PNG 512×768 с прозрачным фоном — и рядом для сравнения скрин текущего SVG. Покажи мне и **жди «ок»**.

## Этап 3 — Экипировка (после «ок»)

Возьми реальный список предметов из базы (`avatar_items` в миграциях, их 32 — не выдумывай) и сделай каждый отдельным мешем: шлемы, доспехи mis→kumush→oltin, щиты, оружие, аксессуары. Внешний вид — по их текущим SVG-версиям.

Каждый предмет привязан к якорной точке (голова, торс, правая рука, левая рука, пояс) и масштабируется под телосложение — не пересекает тело ни на одной из 10 фигур.

## Этап 4 — Рендер слоями

Не рендери комбинации — рендери **слоями**, чтобы фронт складывал картинки как сейчас складывает SVG:

1. Одна ортокамера, один свет, один кадр для всех рендеров — иначе слои не совпадут.
2. На каждый типаж — PNG базовой фигуры; на каждый предмет — PNG только предмета в правильном месте для этого типажа.
3. Порядок слоёв тот же, что в SVG: задняя рука → тело → доспех → передняя рука → голова → шлем → оружие → щит → аксессуар.
4. Файлы: `frontend/public/avatar3d/<tipaj>/…png` + `manifest.json` (слой, предмет, порядок наложения).
5. Каждый PNG ≤120 КБ (+webp рядом); суммарный вес папки скажи мне — больше 5 МБ будем резать.

## Этап 5 — Подключение к фронтенду

- Большое превью в «Qurolxona» (и сцена в профиле, если несложно) показывает 3D-слои выбранного типажа; смена типажа на «Qahramoning» меняет фигуру.
- **SVG не удалять**: карточки выбора типажа остаются SVG-чиби, и SVG — запасной вариант везде, где картинки не загрузились.
- Никаких three.js и новых npm-зависимостей — только наложение готовых PNG.

## Правила

- Стиль детский: спокойная поза, оружие опущено, без крови и агрессии.
- Всё генерируется скриптом — права на модели наши.
- Ничего не ломать: выбор типажа, разблокировки, XP, регистрация, текущий SVG-персонаж.

## Приёмка

1. `blender --background --python tools/blender/render_all.py` отрабатывает и наполняет `frontend/public/avatar3d/`.
2. `npm run build && npm run lint` — зелёные.
3. Jangchi заметно крупнее и шире oddiy-yigit; девушки отличаются пропорциями; malika в 3D узнаваема как малика из SVG.
4. Предметы садятся ровно на все 10 фигур, слои совпадают по кадру.
5. Без картинок всё работает на SVG — ничего не падает.

В конце — сводка: сколько файлов, суммарный вес, время полного рендера, что осталось.
