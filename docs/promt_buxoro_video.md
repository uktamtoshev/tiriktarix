Найди в интернете обучающее видео/фильм **для детей и подростков** про Бухару как центр науки эпохи Саманидов и прикрепи его к карточке «Buxoro: olimlar shahri» в Кинозале. Только эта одна карточка. Схема — та же, что для «Avesto» и «Ipak yo'li» (`docs/promt_avesto_video.md`): два этапа, реализация только после моего одобрения. Уже реализованные превью/модал-плеер переиспользуй без изменений.

## 0. Контекст

- Карточка в `backend/src/main/resources/db/migration/V8__films.sql`: эпизод «Buxoro: olimlar shahri» (HUJJATLI, ~6 daq., сейчас без видео). Суть темы: как Бухара при Саманидах (IX–X вв.) стала центром знаний — библиотеки (та самая, где учился Ибн Сина), учёные и написанные ими книги: Ибн Сина, Рудаки, Наршахи.
- Новую миграцию создавай следующим свободным номером в `db/migration/`.

## Этап 1 — Поиск (WebSearch + WebFetch)

Платформы: YouTube, Mover.uz, Vimeo, Dailymotion, Rutube, каналы узбекских ТВ и образовательных проектов. Формулировки:

- узбекский: «Buxoro somoniylar davri hujjatli film», «Ibn Sino hayoti hujjatli film», «Buxoro ilm markazi tarixi», «somoniylar davlati tarixi video», «Buxoro kutubxonasi Ibn Sino»
- русский: «Бухара город учёных документальный фильм», «Ибн Сина Авиценна фильм для детей», «Саманиды Бухара наука документальный»

Критерии (все обязательны):

1. Образовательное; **светский ракурс — наука, медицина, поэзия, библиотеки** (Ибн Сина, Рудаки), а не религиозная проповедь: продукт светский, детский.
2. Подходит детям/подросткам; если для старших подростков — пометь.
3. Не Shorts и не клип: ≥ 3 минут, URL без `/shorts/`.
4. **Оригинальный канал, не пиратский перезалив** — перезаливы удаляют, ссылка умрёт; у фильмов телеканалов ищи официальный канал.
5. Язык: узбекский приоритетен, русский с пометкой «RU».
6. **Каждая ссылка верифицирована WebFetch'ем**: заголовок, канал, длительность, доступность. Ссылки «из памяти» запрещены; непроверяемая = отклонена.

Результат — таблица топ-3: `платформа | название | канал | язык | длительность | возраст | URL | плюсы/минусы`, рекомендация №1, отклонённые с причинами. **Жди моего «ок»**.

## Этап 2 — Реализация (после одобрения)

- Миграция: `UPDATE films SET video_url = '…', status = 'PUBLISHED', duration_minutes = <фактическая>, source = '<Платформа>: <канал>'` только для этой карточки; `verified = false` (методист отсмотрит).
- Список `/filmlar`: превью-кадр + запуск (YouTube → модал `youtube-nocookie`, iframe только после клика; иная платформа → внешняя ссылка с бейджем, `rel="noopener"`).
- Детальная карточка: блок просмотра «Ko'rish» с атрибуцией канала; шаг 4 конвейера для внешнего видео — честная подпись «Video biriktirildi (tashqi manba)».
- UI-текст — узбекская латиница.

## Ограничения и приёмка

- Трогать только эту карточку; схему `films`, старые миграции, остальные эпизоды не менять; зависимостей не добавлять.
- Приёмка: таблица до реализации; ссылка открывается и совпадает по заголовку; `mvn test`, `npm run build && npm run lint` зелёные; карточка «Buxoro» играет видео, остальные без изменений; в сводке — платформа, язык, возраст, напоминание методисту (verified=false).
