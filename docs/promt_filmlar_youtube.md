# Промт для Claude Code — реальные YouTube-видео в «Kinozal» (filmlar)

> Скопируй всё, что ниже разделителя, в Claude Code в корне репозитория TIRIK TARIX.

---

Сейчас в «Kinozal» все 16 эпизодов — заглушки со стадиями производства (`PLANNED → SCRIPT → IN_REVIEW`), потому что своих видео нет. Задача: **найди для каждой карточки реальное обучающее видео на YouTube (не Shorts), проверь ссылку и прикрепи её к карточке**. Карточки, для которых найдено видео, перестают показывать стадию-заглушку и становятся смотрибельными; для остальных всё остаётся как есть. Работай в два этапа — реализацию начинай только после моего одобрения таблицы находок.

## 0. Изучи контекст

- `backend/src/main/resources/db/migration/V8__films.sql` — список всех 16 эпизодов (темы, эпохи, герои) и constraint `films_published_needs_video`.
- `backend/src/main/java/uz/tiriktarix/film/` — `Film`, `FilmController`, `FilmRepository`.
- `frontend/src/app/(shell)/filmlar/page.tsx`, `frontend/src/components/ui/FilmPoster.tsx`, тип `Film` в `frontend/src/lib/api.ts`.
- `README.md` — правила производительности (дешёвые телефоны!) и принцип достоверности.
- Проверь последний номер миграции в `db/migration/` — новую создавай следующим свободным номером.

## Этап 1 — Поиск и проверка (WebSearch + WebFetch)

Для КАЖДОГО из 16 эпизодов найди лучшее реальное видео на YouTube по теме карточки:

- Запросы сначала на узбекском (напр. «Avesto haqida hujjatli film», «Ipak yo'li tarixi hujjatli»), затем на русском; пробуй несколько формулировок, смотри и каналы узбекских ТВ/образовательных проектов.
- Критерии отбора: образовательное (документальное/лекция/анимация по истории), соответствует теме карточки, длительность **≥ 3 минут** (не Shorts: URL не содержит `/shorts/`, длительность подтверждена), канал выглядит добротно, доступно без ограничений.
- **Каждую ссылку обязательно верифицируй WebFetch'ем страницы видео**: реальный заголовок, канал, длительность (из метаданных страницы, напр. `lengthSeconds`). Ссылки из памяти не выдумывать — только найденные и проверенные сейчас. Мёртвая/непроверяемая ссылка = видео не найдено.
- Если достойного видео по теме нет — честно оставь карточку без видео, не подгоняй мусор.

Результат этапа — таблица: `эпизод → название видео | канал | язык (UZ/RU) | длительность | URL | почему выбрал`. Покажи её и **жди моего «ок»** (я вычеркну неподходящие).

## Этап 2 — Реализация (после одобрения)

### Данные

- Новая Flyway-миграция (следующий свободный номер): для одобренных эпизодов `UPDATE films SET video_url = '…', status = 'PUBLISHED', duration_minutes = <фактическая>, source = 'YouTube: <канал>'`. Constraint `films_published_needs_video` при этом соблюдается сам.
- `verified` оставь `false` — это внешний контент, который ещё должен посмотреть методист. Старые миграции не трогать.

### Фронтенд (`filmlar/page.tsx` + `FilmPoster.tsx`)

- Карточка с видео: вместо emoji — превью-кадр `https://i.ytimg.com/vi/{videoId}/hqdefault.jpg` (обычный `<img>` с `loading="lazy"` и alt), поверх — кнопка play в стиле проекта; внизу — длительность и бейдж канала (атрибуция обязательна), пометка языка «RU», если видео русскоязычное.
- Клик → модал с встроенным плеером `https://www.youtube-nocookie.com/embed/{videoId}?rel=0` (детская платформа — только nocookie-домен) + кнопка «YouTube'da ochish» (новая вкладка, `rel="noopener"`).
- **Iframe не грузить до клика** — только превью-картинка (facade-паттерн), это критично для слабых телефонов. Модал закрывается по Esc и клику мимо, фокус-ловушка, `aria-label` на узбекском.
- Карточки без видео выглядят как сейчас (стадия производства). Утилита `videoId` из URL — одна, с тестом на форматы `watch?v=`, `youtu.be/`.
- Весь UI-текст — узбекская латиница (напр. кнопка «Ko'rish», бейдж «Tashqi manba»).

## Ограничения

- Не менять схему таблицы `films` и логику стадий — только данные и отображение.
- Никаких Shorts, плейлистов и каналов целиком — только конкретные видео.
- Не добавлять зависимостей (никаких react-player и т.п. — чистый iframe в модале).
- README: обнови описание Кинозала (что часть эпизодов — курируемые внешние видео с атрибуцией).

## Приёмка

1. Таблица находок показана и одобрена мной до реализации.
2. Каждая записанная в миграцию ссылка отвечает 200 и открывается.
3. `mvn test` и `npm run build && npm run lint` — зелёные.
4. На `/filmlar`: карточки с видео показывают превью и играют в модале (iframe появляется только после клика); карточки без видео — как раньше.
5. Ни одной ссылки на `/shorts/`; у каждого видео указан канал.

В конце — сводка: сколько эпизодов закрыто видео, сколько осталось в производстве, список того, что методисту нужно отсмотреть.
