# Промт для Claude Code — переименовать страницу экипировки «Xazina» → «Qurolxona»

> Скопируй всё, что ниже разделителя, в Claude Code в корне репозитория TIRIK TARIX.

---

В проекте конфликт названий: **«Xazina» называется и библиотека (карточки фактов), и страница экипировки персонажа**. Библиотека оставляет своё имя, **страницу экипировки переименуй в «Qurolxona»** (оружейная палата).

## Что сделать

1. Найди все места, где страница экипировки называется «Xazina», и переименуй в «Qurolxona»:
   - маршрут `/xazina` → `/qurolxona` (папка страницы, все `Link`/`router.push`, редиректы после регистрации, если есть);
   - заголовок страницы и подзаголовок, пункт в навигации `Header.tsx`, кнопка «Xazina» на странице профиля, тексты кнопок и подсказок;
   - `docs/`-промты не трогай (это история решений), но **README обнови**.
2. **Библиотеку и её маршрут не трогай вообще** — она остаётся «Xazina».
3. Проверь, что нигде не осталось старого пути: поиск по репозиторию на `xazina` должен давать только библиотеку.
4. Если где-то есть сохранённые ссылки на старый маршрут (например, в тексте маскота или в достижениях) — поправь и их.

## Правила

- Только переименование: логику экипировки, разблокировок и данные не менять; миграции не нужны.
- Узбекская латиница, стиль текстов как в проекте.
- Ничего не ломать: профиль, шапка, регистрация, библиотека.

## Приёмка

1. `npm run build && npm run lint` — зелёные.
2. Переход на `/qurolxona` работает, экипировка на месте, надеть/снять предмет работает как раньше.
3. В шапке и профиле пункт называется «Qurolxona» и ведёт туда же.
4. Библиотека по-прежнему «Xazina» и работает без изменений.
5. Поиск по коду `Xazina` находит только библиотеку.

В конце — список изменённых файлов и одна строка: где ещё встречалось старое название.
