# Промт для Claude Code — подключить портрет Амира Темура

> Сначала сохрани картинку из Gemini на диск (например, в `~/Downloads/temur.png`), потом скопируй всё, что ниже разделителя, в Claude Code в корне репозитория TIRIK TARIX — и поправь путь к файлу в первой строке, если он другой.

---

Добавь портрет Амира Темура в проект. Исходный файл: `~/Downloads/temur.png` (если по этому пути нет — спроси меня, не ищи сам по всему диску).

## 1. Подготовь файл

- Оптимизируй под слабые телефоны: большая сторона ~800px, вес ≤ 300 КБ, формат webp (или jpg, если конвертера нет). Используй то, что есть на машине: `sips` / ImageMagick / `cwebp`. Новых npm-зависимостей не добавляй.
- Положи результат в `frontend/public/portretlar/amir-temur.webp` (папка `portretlar` уже существует — посмотри, как названы файлы в ней, и следуй той же конвенции имён, если она есть).

## 2. Пропиши портрет в данных героя

- Найди героя Амира Темура в сид-миграциях (`backend/src/main/resources/db/migration/`) — возьми его реальный `slug` оттуда, не выдумывай.
- Новая Flyway-миграция следующим свободным номером: `UPDATE heroes SET portrait_url = '/portretlar/amir-temur.webp', portrait_kind = 'ARTWORK', portrait_caption_uz = 'Zamonaviy illyustratsiya (Zafarnoma miniatyuralari asosida, AI yordamida)', portrait_source = 'TIRIK TARIX loyihasi uchun yaratilgan, 2026' WHERE slug = '<реальный slug>'`.
- Подпись и source — именно честные, как выше: это современная иллюстрация, а не исторический артефакт; принцип достоверности проекта требует это указывать. Если в схеме поля называются иначе — сверься с `Hero.java` и V9-миграцией.

## 3. Проверь отображение

- Страница героя `qahramonlar/[slug]` и галерея «Ajdodlar zali»: если фронтенд уже умеет показывать `portraitUrl` (тип `Hero` в `lib/api.ts` содержит эти поля) — просто проверь, что картинка видна, подпись и источник выводятся, а при отсутствии файла остаётся эмодзи-фолбэк.
- Если где-то портрет ещё не рендерится (например, в `HeroMedallion` только эмодзи) — добавь аккуратный вывод изображения в существующем стиле (гравированное золотое кольцо медальона сохраняется), с `alt="Amir Temur portreti"`, `loading="lazy"`, без layout shift (фиксированные размеры).
- У других героев ничего не должно измениться.

## 4. Приёмка

1. `mvn test`, `npm run build && npm run lint` — зелёные.
2. Файл в `public/portretlar/` весит ≤ 300 КБ; страница героя не тормозит на мобильной ширине.
3. На странице Темура виден портрет с подписью «Zamonaviy illyustratsiya…» и источником; фолбэк на эмодзи работает, если файл убрать.
4. Улугбек и Навои — без изменений.
