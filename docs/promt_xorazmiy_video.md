Найди в интернете обучающее видео/фильм **для детей и подростков** про аль-Хорезми и происхождение слова «алгоритм» и прикрепи его к карточке «Al-Xorazmiy va algoritm» в Кинозале. Только эта одна карточка. Схема — та же, что для предыдущих карточек (`docs/promt_avesto_video.md`): два этапа, реализация только после моего одобрения. Уже реализованные превью/модал-плеер переиспользуй без изменений.

## 0. Контекст

- Карточка в `backend/src/main/resources/db/migration/V8__films.sql`: эпизод «Al-Xorazmiy va algoritm» (SHORT, ~3 daq., эпоха `arab`, сейчас без видео). Суть темы: Мухаммад аль-Хорезми (IX век, родом из Хорезма, работал в Доме мудрости в Багдаде) — почему весь мир говорит «алгоритм» (латинизация его имени Algoritmi) и «алгебра» (от «аль-джабр» из его книги), как через него к миру пришли десятичные цифры.
- Новую миграцию создавай следующим свободным номером в `db/migration/`.

## Этап 1 — Поиск (WebSearch + WebFetch)

Платформы: YouTube, Mover.uz, Vimeo, Dailymotion, Rutube, каналы узбекских ТВ, образовательные и научпоп-каналы (для этой темы научпоп по истории математики — отличный вариант). Формулировки:

- узбекский: «Al-Xorazmiy hujjatli film», «Muhammad al-Xorazmiy hayoti video», «algoritm so'zi qayerdan kelgan», «Al-Xorazmiy algebra tarixi»
- русский: «аль-Хорезми документальный фильм», «откуда произошло слово алгоритм видео», «аль-Хорезми алгебра история математики», «Дом мудрости Багдад учёные фильм»

Критерии (все обязательны):

1. Образовательное: документалка, научпоп или анимация об истории математики; короткий мультик про происхождение слова «алгоритм» — идеален для 3-минутной карточки.
2. Светский ракурс: наука Дома мудрости, математика, а не религиозная тематика эпохи.
3. Подходит детям/подросткам; если для старших — пометь.
4. Не Shorts и не клип: ≥ 3 минут, URL без `/shorts/`.
5. **Оригинальный канал, не пиратский перезалив.**
6. Язык: узбекский приоритетен, русский с пометкой «RU».
7. **Каждая ссылка верифицирована WebFetch'ем**: заголовок, канал, длительность, доступность. Ссылки «из памяти» запрещены; непроверяемая = отклонена.

Результат — таблица топ-3: `платформа | название | канал | язык | длительность | возраст | URL | плюсы/минусы`, рекомендация №1, отклонённые с причинами. **Жди моего «ок»**.

## Этап 2 — Реализация (после одобрения)

- Миграция: `UPDATE films SET video_url = '…', status = 'PUBLISHED', duration_minutes = <фактическая>, source = '<Платформа>: <канал>'` только для этой карточки; `verified = false` (методист отсмотрит).
- Список `/filmlar`: превью-кадр + запуск (YouTube → модал `youtube-nocookie`, iframe только после клика; иная платформа → внешняя ссылка с бейджем, `rel="noopener"`).
- Детальная карточка: блок просмотра «Ko'rish» с атрибуцией канала; шаг 4 конвейера для внешнего видео — честная подпись «Video biriktirildi (tashqi manba)».
- UI-текст — узбекская латиница.

## Ограничения и приёмка

- Трогать только эту карточку; схему `films`, старые миграции, остальные эпизоды не менять; зависимостей не добавлять.
