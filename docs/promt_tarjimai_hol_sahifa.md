# Промт для Claude Code — отдельная страница биографии по кнопке «Batafsil»

> Скопируй всё, что ниже разделителя, в Claude Code в корне репозитория TIRIK TARIX. Это уточнение к прошлой задаче: кнопка «Batafsil» уже стоит на карточках — теперь она должна вести на **отдельную полноценную страницу**, а не на якорь.

---

Кнопка «Batafsil» на карточках фактов сейчас ведёт на страницу героя. Измени: она должна открывать **отдельную страницу — биографию**, целиком посвящённую этому человеку: его жизнь, путь, дела, эпоха, наследие. Для карточек эпохи — аналогичную страницу об эпохе.

## 1. Новые страницы и маршруты

- **Биография человека:** `/qahramonlar/<slug>/tarjimai-hol` — новая страница, не модалка и не якорь.
- **Страница эпохи:** `/davrlar/<code>` — для карточек, привязанных к эпохе, а не к человеку.
- Кнопка «Batafsil» на карточке ведёт на соответствующую страницу; у карточки без героя и эпохи кнопки нет.
- На новой странице обязательно: хлебные крошки или кнопка «← Ortga», ссылка «Suhbatni boshlash» (диалог с этим предком) и корректный `<title>` вида «Abu Rayhon Beruniy — tarjimai hol».

## 2. Из чего строится биография (главное правило)

**Ни одного нового факта от себя.** Не бери сведения из своих знаний, не пересказывай Википедию, не «дополняй» биографию правдоподобным текстом. Страница собирается **только** из того, что уже лежит в базе и проверено. Это принцип достоверности №1 проекта: если данных мало — страница будет короткой, и это нормально.

Разделы страницы, сверху вниз:

1. **Шапка.** Портрет в золотом медальоне (`portrait_url` + честная подпись `portrait_caption_uz`), имя `name_uz`, звание `title_uz`, годы жизни `birth_year — death_year`, эпоха.
2. **«Hayoti»** — текст `bio_uz` из базы.
3. **«Hayot yo'li»** — вертикальная лента фактов **этого героя** из `fact_cards`: тема, факт, источник у каждого. Если в тексте факта есть год — покажи его слева как метку и отсортируй ленту по годам; факты без года — после них, в исходном порядке.
4. **«U yashagan davr»** — события из `historical_events`, попадающие в годы его жизни (`year_from` между `birth_year` и `death_year`; если год рождения неизвестен — бери события его эпохи). Это уже проверенные данные, и именно они делают страницу живой: видно, что происходило вокруг, пока он жил.
5. **«Bilimingni sinab ko'r»** — кнопка микро-квиза этого героя (эндпоинт уже есть) и, если у героя есть фильм в Кинозале, — карточка-ссылка на него.
6. **«Manbalar»** — внизу единым списком все источники, использованные на странице (без дублей).

Для страницы эпохи `/davrlar/<code>` — та же логика: название и описание эпохи, годы, лента её событий, карточки фактов эпохи с источниками, ссылка на тест эпохи и фильмы этой эпохи, список источников.

## 3. Оформление

- Стиль — существующий: тёмный камень для страницы, **пергамент для читаемых блоков** (биография и факты — это чтение, им положен пергамент), золотая инкрустация, `Panel` / `SectionTitle` / `CornerFrame` / `HeroMedallion` из UI-кита. Новых компонентов не изобретай.
- Лента «Hayot yo'li» — вертикальная линия с золотыми точками-годами, как временная шкала.
- Входные анимации — существующие `tt-reveal` / `tt-rise`, ничего тяжёлого; параллакс и декоративная анимация только на ≥1024px и с учётом `prefers-reduced-motion`.
- Мобильные: одна колонка, портрет сверху, крупный читаемый текст, кнопки от 44px.
- Контраст AA: тёмный текст на пергаменте, золото только для акцентов и заголовков.

## 4. Данные и бэкенд

- Скорее всего всё нужное уже отдают существующие эндпоинты (`/api/heroes/{slug}`, `/api/library/factcards?heroSlug=`, `/api/events?eraCode=`, `/api/films?heroSlug=`). **Сначала проверь** — и только если реально не хватает, добавь один эндпоинт-агрегатор `GET /api/heroes/{slug}/biography`, который отдаёт всё разом. Новых таблиц и миграций не создавай.
- Если у героя нет портрета или мало фактов — страница всё равно должна нормально выглядеть: фолбэк-эмодзи вместо портрета, раздел без данных просто не показывается (не пустой блок с заголовком).

## 5. Правила

- Весь текст — узбекская латиница; в UI никакого русского и английского.
- Не ломать: библиотеку и её фильтры, страницу героя, чат, квизы, Кинозал.
- Новых npm-зависимостей нет; правила производительности из README соблюдены.
- README: короткий абзац про страницы биографии и эпохи.

## 6. Приёмка

1. `npm run build && npm run lint` (и `mvn test`, если бэкенд тронут) — зелёные.
2. Клик «Batafsil» на карточке Беруни открывает `/qahramonlar/abu-rayhon-beruniy/tarjimai-hol` — отдельную страницу с портретом, биографией, лентой жизни и событиями его времени.
3. На странице у каждого факта виден источник, внизу общий список источников; выдуманного текста нет ни строчки.
4. Клик «Batafsil» на карточке эпохи открывает страницу эпохи с её событиями.
5. У героя с малым количеством данных страница не выглядит сломанной — просто короче.
6. Переход «Ortga» возвращает в библиотеку; ссылка «Suhbatni boshlash» открывает диалог с этим предком.
7. На телефоне всё читается, ничего не «прыгает» при загрузке.
