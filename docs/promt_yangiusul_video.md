Найди в интернете обучающее видео/фильм **для детей и подростков** про джадидов и новометодные школы и прикрепи его к карточке «Yangi usul maktablari» в Кинозале. Только эта одна карточка. Схема — та же, что для предыдущих карточек (`docs/promt_avesto_video.md`): два этапа, реализация только после моего одобрения. Уже реализованные превью/модал-плеер переиспользуй без изменений.

## 0. Контекст

- Карточка в `backend/src/main/resources/db/migration/V8__films.sql`: эпизод «Yangi usul maktablari» (SHORT, ~3 daq., эпоха `jadidlar`, сейчас без видео). Суть темы: зачем джадиды открыли новые школы и чем они отличались от старых — звуковой метод обучения грамоте, парты и карты, арифметика и география, просветители (Бехбуди, Авлони, Мунаввар Кары).
- Новую миграцию создавай следующим свободным номером в `db/migration/`.

## Этап 1 — Поиск (WebSearch + WebFetch)

Платформы: YouTube, Mover.uz, Vimeo, Dailymotion, Rutube, каналы узбекских ТВ и образовательных проектов (по джадидам в Узбекистане много свежего контента — выбор должен быть).

- узбекский: «jadidlar hujjatli film», «yangi usul maktablari tarixi», «jadidchilik harakati video», «Mahmudxo'ja Behbudiy hujjatli film», «Abdulla Avloniy maktab»
- русский: «джадиды документальный фильм», «новометодные школы Туркестана», «джадидизм просветители история»

Критерии (все обязательны):

1. Образовательное: акцент на **школы и просвещение** — чем новый метод отличался от старого, что изменилось для учеников. Не политика и не трагический финал движения (это другая карточка эпохи) — тема светлая.
2. Нейтральный светский тон, без религиозной и политической полемики.
3. Подходит детям/подросткам; если для старших — пометь.
4. Не Shorts и не клип: ≥ 3 минут, URL без `/shorts/`.
5. **Оригинальный канал, не пиратский перезалив.**
6. Язык: узбекский приоритетен, русский с пометкой «RU».
7. **Каждая ссылка верифицирована WebFetch'ем**: заголовок, канал, длительность, доступность. Ссылки «из памяти» запрещены; непроверяемая = отклонена.

Результат — таблица топ-3: `платформа | название | канал | язык | длительность | возраст | URL | плюсы/минусы`, рекомендация №1, отклонённые с причинами. **Жди моего «ок»**.

## Этап 2 — Реализация (после одобрения)

- Миграция: `UPDATE films SET video_url = '…', status = 'PUBLISHED', duration_minutes = <фактическая>, source = '<Платформа>: <канал>'` только для этой карточки; `verified = false` (методист отсмотрит).
- Список `/filmlar`: превью-кадр + запуск (YouTube → модал `youtube-nocookie`, iframe только после клика; иная платформа → внешняя ссылка с бейджем, `rel="noopener"`).
- Детальная карточка: блок просмотра «Ko'rish» с атрибуцией канала; шаг 4 конвейера для внешнего видео — честная подпись «Video biriktirildi (tashqi manba)».
- UI-текст — узбекская латиница.
