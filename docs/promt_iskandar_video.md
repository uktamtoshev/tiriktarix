Найди в интернете обучающее видео/фильм **для детей и подростков** про поход Александра Македонского в Среднюю Азию и прикрепи его к карточке «Iskandar Sirdaryo bo'yida» в Кинозале. Только эта одна карточка. Схема — та же, что для предыдущих карточек (`docs/promt_avesto_video.md`): два этапа, реализация только после моего одобрения. Уже реализованные превью/модал-плеер переиспользуй без изменений.

## 0. Контекст

- Карточка в `backend/src/main/resources/db/migration/V8__films.sql`: эпизод «Iskandar Sirdaryo bo'yida» (SHORT, ~3 daq., эпоха `antik`, сейчас без видео). Суть темы: 329 год до н.э. — поход Искандара Зулкарнайна доходит до Мовароуннахра (Согдианы): Александрия Эсхата на Сырдарье, сопротивление Спитамена — и почему завоеватель не смог здесь надолго остаться.
- Новую миграцию создавай следующим свободным номером в `db/migration/`.

## Этап 1 — Поиск (WebSearch + WebFetch)

Платформы: YouTube, Mover.uz, Vimeo, Dailymotion, Rutube, каналы узбекских ТВ и образовательных проектов. Формулировки:

- узбекский: «Iskandar Zulqarnayn Movarounnahr tarixi», «Spitamen qo'zg'oloni video», «makedoniyalik Iskandar O'rta Osiyo hujjatli», «Iskandar Sirdaryo tarixi»
- русский: «Александр Македонский Средняя Азия документальный», «Спитамен восстание Согдиана», «Александрия Эсхата Худжанд история», «поход Александра в Согдиану фильм»

Критерии (все обязательны):

1. Образовательное: документалка/лекция/анимация. **Приоритет — видео с акцентом на Среднюю Азию** (Согдиана, Спитамен, Сырдарья), а не общая биография Александра про Грецию и Персию. Если точного нет — допусти́м общий образовательный фильм о походе с пометкой «тема шире»: решу я.
2. **Не отрывки из художественных фильмов** (голливудские «Александры» и нарезки из них — отсев): только документальное/образовательное.
3. Подходит детям/подросткам: батальные темы без натуралистичного насилия; если для старших — пометь.
4. Не Shorts и не клип: ≥ 3 минут, URL без `/shorts/`.
5. **Оригинальный канал, не пиратский перезалив.**
6. Язык: узбекский приоритетен, русский с пометкой «RU».
7. **Каждая ссылка верифицирована WebFetch'ем**: заголовок, канал, длительность, доступность. Ссылки «из памяти» запрещены; непроверяемая = отклонена.

Результат — таблица топ-3: `платформа | название | канал | язык | длительность | возраст | соответствие теме (точное/шире) | URL | плюсы/минусы`, рекомендация №1, отклонённые с причинами. **Жди моего «ок»**.

## Этап 2 — Реализация (после одобрения)

- Миграция: `UPDATE films SET video_url = '…', status = 'PUBLISHED', duration_minutes = <фактическая>, source = '<Платформа>: <канал>'` только для этой карточки; `verified = false` (методист отсмотрит).
- Список `/filmlar`: превью-кадр + запуск (YouTube → модал `youtube-nocookie`, iframe только после клика; иная платформа → внешняя ссылка с бейджем, `rel="noopener"`).
- Детальная карточка: блок просмотра «Ko'rish» с атрибуцией канала; шаг 4 конвейера для внешнего видео — честная подпись «Video biriktirildi (tashqi manba)».
- UI-текст — узбекская латиница.

## Ограничения и приёмка

- Трогать только эту карточку; схему `films`, старые миграции, остальные эпизоды не менять; зависимостей не добавлять.
