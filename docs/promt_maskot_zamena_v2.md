Замени внешность маскота проекта (`frontend/src/components/Mascot.tsx`) на **серебряный вариант «Парадная форма» — БЕЗ серёжки**. Меняется только внешний вид; имя, легенда, поведение и механики маскота — прежние. Если ты уже заменил маскота на бежевый вариант по прошлому промту — не переделывай всё, а внеси две правки: тон и серёжку (см. ниже). Если ещё не заменял — делай сразу по этому описанию.

## 1. Описание финального дизайна

- Круглая крупная голова, **серебристо-стальной тон** «кожи» (холодный светло-серый с лёгким голубым отливом — бери из steel-палитры проекта), маленькие круглые ушки сверху по бокам.
- На лбу — золотая тиара-орнамент: дуга с тремя точками и зубчиком по центру.
- Большие круглые глаза с бликами, маленький серый нос, добрая улыбка, розовые румяна, пара серых веснушек-пятнышек на лбу.
- **Серёжки НЕТ** (в прошлой версии описания была золотая серёжка-сердечко — убрать/не рисовать).
- Тёмно-синий (obsidian) парадный чапан с воротником, поднятым к ушам: V-образный вырез обрамляет лицо, золотая окантовка по краю воротника, золотая планка по центру, на груди золотые ромбики — по три с каждой стороны, убывающего размера.
- Палитра — строго токены проекта (obsidian/steel/zar), плоский стиль, чистый SVG. Серебристый маскот + золото = буквально «TEMIR VA ZAR», следи, чтобы оттенки совпадали с токенами.

## 2. Сохранить ВСЁ поведение (как в прошлом промте)

- Прячется за нижним краем экрана — торчат только ушки; выпрыгивает с squash-stretch-анимацией, говорит и ныряет обратно.
- Настроения через событие `tirik-mascot` (`tellMascot()`): `happy` — улыбка; `sad` — грусть + слеза; `celebrate` — искры. Выражения — минимальными правками поверх базового лица.
- `activeToday`, тайминги, реплики — не трогать. Чистый SVG без растров, анимации как сейчас, `prefers-reduced-motion` уважается.

## 3. Не перепутать

- Экран выбора персонажа и аватары игроков не трогать — этот промт только про маскота.
- Маскот должен визуально отличаться от аватаров игроков: его фирменные знаки — серебряный тон, тиара и парадный чапан с поднятым воротником. Если такой же убор есть у аватаров — скажи мне, разведём.
- README: поправь описание внешности маскота парой строк.

## 4. Приёмка

1. `npm run build && npm run lint` — зелёные.
2. Маскот серебряный, без серёжки, с тиарой; из-за нижнего края торчат ушки; выпрыгивает с прежней анимацией.
3. Три настроения различимы (happy / sad со слезой / celebrate с искрами) — проверь через `tellMascot` из консоли и реальным сценарием (тест ≥80%).
4. Регистрация и аватары игроков не изменились; `prefers-reduced-motion` отключает прыжки.
