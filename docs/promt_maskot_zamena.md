## 1. Найди исходник дизайна

Вариант «Парадная форма v4 · Ж (v7)» — из галереи вариантов, которую ты рисовал раньше (превью-страница/мокап с подписями версий). Поищи его в репозитории (компоненты превью, мокапы, git-история). Если исходник не найдётся — воссоздай точно по описанию:

- Круглая крупная голова, тёплый бежевый тон кожи, маленькие круглые ушки сверху по бокам.
- На лбу — золотая тиара-орнамент (дуга с тремя точками и зубчиком по центру).
- Большие круглые глаза с бликами, маленький нос, добрая улыбка, розовые румяна на щеках, пара бежевых веснушек-пятнышек.
- У левого уха — золотая серёжка-сердечко с тёмной точкой.
- Тёмно-синий (obsidian) парадный чапан с **воротником, поднятым к ушам**: V-образный вырез воротника обрамляет лицо, золотая окантовка по краю воротника и золотая планка-молния по центру, на груди — золотые ромбики (по три с каждой стороны, убывающего размера).
- Палитра — строго токены проекта (obsidian/steel/zar/parchment), стиль плоский, чистый SVG.

## 2. Замени арт в Mascot.tsx, сохранив ВСЁ поведение

Прочитай `frontend/src/components/Mascot.tsx` и README (раздел про маскота). Должно сохраниться без изменений:

- Прячется за нижним краем экрана — **торчат только ушки** (у нового дизайна ушки есть — используй их).
- Выпрыгивает с пружинистой squash-stretch-анимацией, говорит реплику и ныряет обратно.
- Настроения через событие `tirik-mascot` (`tellMascot()` в `lib/api.ts`): `happy` — радуется; `sad` — грустит со слезой; `celebrate` — празднует с искрами. Выражения делай минимальными правками поверх базового лица (рот дугой вниз + слеза; звёздочки вокруг при celebrate), а не отдельными перерисовками.
- Признак «занимался сегодня» (`activeToday`), тайминги появления, реплики — не трогать.
- Производительность: чистый SVG без растров и фильтров, анимации как сейчас (CSS/framer-motion), уважение `prefers-reduced-motion`, ничего тяжёлого на мобильных.

Старый SVG-арт барсёнка из компонента удали (в git-истории он и так останется).

1. `npm run build && npm run lint` — зелёные.
