# Редизайн «Tirik tarix» — арт-дирекшн «TEMIR VA ZAR» (Сталь и Золото)

Версия 1.0 · 29.07.2026

---

## 1. Почему меняем

Текущий дизайн — светлый Duolingo-подобный (бирюза + янтарь, эмодзи, скруглённые
карточки). Он дружелюбный, но **не передаёт масштаб темы**: империи, полководцы,
обсерватория Улугбека, тысячелетия. Ребёнок 10–15 лет не чувствует, что входит
в нечто великое, — он видит обычное учебное приложение.

**Новая задача:** каждый вход на сайт = вход в **сокровищницу / зал предков**.
Грандиозность, металл, золото, камень, силуэты воинов — при сохранении
читаемости и детской дружелюбности (маскот Илвирс остаётся, он «проводник»).

## 2. Концепция «TEMIR VA ZAR»

**Метафора:** ночной музей-крепость. Тёмный камень стен, золотая инкрустация
(зар), дамасская сталь, свет факела. Пользователь идёт через **Врата
(Darvozalar)** — каждый модуль это врата в свой мир.

**Три материала системы:**

| Материал | Где | Смысл |
|---|---|---|
| **Камень/обсидиан** | фоны, оболочка | вечность, крепость |
| **Зар (золото)** | акценты, рамки, заголовки | ценность знания, наследие |
| **Пергамент** | зоны чтения (факты, чат, разборы) | источник, документ |

**Воины как акцент, а не как милитаризм:** силуэты на горизонте, штандарты
(туғ), гравированные орнаменты доспеха, конные лучники в паттернах. Кровь и
насилие — исключены (аудитория 10–15). Красный (`qon`) используется точечно:
только «сложный тест», «битва», «ошибка».

### 2.1 Палитра

```
Основа (камень)
--tt-obsidian     #0A0D13   фон приложения
--tt-basalt       #111621   секции
--tt-steel        #1A2130   поверхности/карточки
--tt-steel-2      #262F42   бордеры, разделители

Зар (золото) — главный акцент
--tt-zar          #C8A247   основной
--tt-zar-bright   #F3D98B   блик, hover, свет
--tt-zar-deep     #7A5F1C   тень золота, градиент

Смысловые
--tt-feruza       #2E8A87   диалог/знание (наследие старого бренда)
--tt-qon          #9B2E22   война/сложность/ошибка (точечно)
--tt-nil          #35507A   вода/карты/эпохи

Пергамент и текст
--tt-parchment    #EDE2C8   текст на тёмном / фон читальных зон
--tt-marble       #F7F2E6   заголовки на тёмном
--tt-dust         #98A0B3   вторичный текст
```

Контраст: `--tt-parchment` на `--tt-obsidian` = 13.7:1, `--tt-dust` на
`--tt-basalt` = 7.4:1, `--tt-zar` на `--tt-obsidian` = 8.1:1 — все ≥ AA.

### 2.2 Типографика

| Роль | Шрифт | Начертание |
|---|---|---|
| Дисплей (H1, H2, названия врат) | **Cinzel** | 600/700, CAPS, tracking +0.06em |
| Цитаты героев | **Cormorant Garamond** italic | 500 |
| Текст/UI | **Inter** | 400/500/600/700 |
| Маскот/игровые бейджи | Baloo 2 (оставляем) | 700 |

Cinzel — шрифт римских монументальных надписей: буквально «высечено в камне».
Он даёт грандиозность одним касанием. Все три поддерживают latin-ext (узбекская
латиница с `oʻ`, `gʻ`).

Шкала: 12 / 14 / 16 / 18 / 22 / 28 / 36 / 48 / 64 / 84 (clamp на мобильных).

### 2.3 Форма и материал

- **Радиусы уменьшаем**: 4 / 8 / 14 px вместо 20–32. Камень не бывает
  мягко-скруглённым. Игровые элементы (XP, бейджи) остаются pill.
- **Гравированная рамка**: двойная волосяная линия золота + угловые орнаменты
  (SVG-уголки в стиле гириха).
- **Тени**: не «мягкое облако», а глубина ниши — `0 24px 60px -20px rgba(0,0,0,.8)`
  + внутренний блик `inset 0 1px 0 rgba(243,217,139,.14)`.
- **Текстуры-слои** (все SVG/CSS, без картинок): гирих-сетка, зерно стали
  (noise), виньетка, парящая пыль.

### 2.4 Движение

| Токен | Значение | Где |
|---|---|---|
| `--tt-ease` | cubic-bezier(.16,1,.3,1) | всё раскрытие |
| `--tt-fast` | 180ms | hover |
| `--tt-slow` | 700ms | входы секций |
| `--tt-epic` | 1200ms | герой лендинга |

Ключевые эффекты: **золотой сполох** (световая полоса идёт по металлу карточки
при наведении), **пробуждение рамки** (золото загорается от угла), параллакс
слоёв героя, медленное вращение гирих-мандалы. Всё под
`prefers-reduced-motion: reduce`.

## 3. Новая структура лендинга

```
┌─ HERO «SARHAD» (граница/горизонт), 100vh
│   слои: небо-градиент → гирих-мандала (медленно вращается)
│          → силуэты гор → силуэты воинов и штандартов → пыль
│   H1 Cinzel CAPS: «QAHRAMONLAR HAQIDA OʻQIMA — ULAR BILAN GAPLASH»
│   CTA: «Darvozadan kir →»  (золотая кнопка со сполохом)
│   вниз: индикатор скролла
│
├─ DARVOZALAR — 6 карточек-врат (главное меню продукта)
│   1. Ajdodlar bilan suhbat   → /qahramonlar   (разговор с предками)
│   2. Tarixiy voqealar        → /voqealar      (исторические события)
│   3. Zamon xaritalari        → /xaritalar     (карты времён)      NEW
│   4. Hujjatli filmlar        → /filmlar       (документалки/фильмы) NEW
│   5. Sinovlar                → /testlar       (тесты)
│   6. Xazina — kutubxona      → /kutubxona     (библиотека)
│
├─ SALNOMA — лента 8 эпох (горизонтальная, золотая ось времени)
├─ KUNLIK TOPISHMOQ — «сирли ўрама», загадка дня как свиток
└─ MANIFEST — «ИИ создаёт форму — люди отвечают за правду» + цифры проекта
```

Каждые Врата = карточка-портал: тёмный камень, гравированная золотая рамка,
крупный символ (SVG-эмблема, не эмодзи), название Cinzel, одна строка описания,
на hover — сполох золота + подъём + проявление арки.

## 4. Спринты

Каждый спринт — самостоятельный, заканчивается работающим экраном.

### Спринт 1 — Дизайн-фундамент ✅
- `globals.css`: полный набор токенов (цвет, типографика, spacing, радиусы,
  тени, motion) в `@theme` Tailwind 4.
- Подключить Cinzel + Cormorant Garamond + Inter, оставить Baloo 2.
- Слои-текстуры: `.tt-girih`, `.tt-grain`, `.tt-vignette`, `.tt-dust`.
- Утилиты: `.tt-engraved` (гравированная рамка), `.tt-gold-sweep`,
  `.tt-ignite`, `.tt-reveal`.
- `prefers-reduced-motion` для всего.
- **Готово:** тёмная тема применена, старые классы не ломают страницы.

### Спринт 2 — UI-кит и оболочка ✅
- `components/ui/`: `Button` (zar / steel / ghost × sm/md/lg), `GateCard`,
  `Panel` (steel / parchment), `Badge`, `SectionTitle` с орнаментом,
  `Ornament` (углы, разделители, туғ-штандарт), `Stat`.
- `Header`: монументальный — золотой герб-логотип, Cinzel-навигация, XP и
  стрик как «печати», mobile-меню как раскрывающиеся врата.
- `Footer`: каменное основание с гирихом и манифестом.
- `Mascot`: перекрасить под тёмную тему (снежный барс в золотом свете).
- **Готово:** страница-песочница `/ui` со всеми компонентами.

### Спринт 3 — Лендинг ✅
- Hero «Sarhad» с параллаксом и слоями SVG (горы, воины, мандала, пыль).
- Секция Врат (6 карточек).
- Лента эпох `Salnoma` (данные `/api/eras`).
- Загадка дня как свиток.
- Манифест + цифры.
- **Готово:** новая главная, проверена в браузере на desktop/mobile.

### Спринт 4 — «Разговор с предками» ✅
- `/qahramonlar`: «Зал предков» — портретные врата героев с годами жизни и
  гербом, крупные, с золотой рамкой.
- `/qahramonlar/[slug]`: сцена сеанса — портрет героя слева, свиток-диалог
  справа; сообщения героя на пергаменте с печатью-источником; отказы
  («Bu haqda tarix sukut saqlaydi») подаются как гравированная надпись.
- Микро-квиз в новом стиле.
- **Готово:** ядро М1 в новой системе.

### Спринт 5 — Карты времён (новый модуль) ✅
- Backend: таблица `map_features` (`TERRITORY | CITY | ROUTE`) +
  `GET /api/maps?eraCode=`; миграция `V7__map_features.sql` с сид-данными на все
  8 эпох. Города живут вне эпох и фильтруются по `min_year`/`max_year`.
- Единая система координат задана в миграции: viewBox `0 0 1000 700`,
  `x = (долгота − 55) × 50`, `y = (47 − широта) × 58.333` — фронтенд не считает
  проекцию.
- Frontend `/xaritalar`: базовая карта (Арал, Амударья, Сырдарья, Зарафшан,
  Кызылкум, Каракумы, Тянь-Шань, Памир), лента эпох, слои поверх неё; маршруты
  прочерчиваются золотом (`pathLength="1"` + `stroke-dashoffset`), клик по слою →
  карточка с описанием и источником.
- Границы схематичны и записаны с `verified = false` → значок «Sxematik».
- **Готово:** новый модуль в меню Врат.

### Спринт 6 — Документалки и фильмы (новый модуль) ✅
- Backend: таблица `films` + `GET /api/films?eraCode=&heroSlug=`; миграция
  `V8__films.sql` с 16 запланированными эпизодами.
- Таблица хранит стадию конвейера `PLANNED → SCRIPT → IN_REVIEW → PUBLISHED`;
  CHECK не даёт опубликовать эпизод без `video_url`.
- Frontend `/filmlar`: кинозал — афиши в золотых рамках с перфорацией плёнки,
  фильтр по эпохам, панель сеанса с синопсисом, источником сценария и текущей
  стадией производства. Плеер готов и включается, когда появится `videoUrl`.
- Готового видео нет (анимация — фаза 2), и интерфейс говорит это прямо,
  а не обещает «скоро».

### Спринт 6 — исходный план
- Backend: таблица `films` (название, эпоха/герой, длительность, тип
  `SHORT|DOC|FEATURE`, источник видео, постер, описание, проверено методистом)
  + `GET /api/films?eraCode=&heroSlug=`; миграция + сид.
- Frontend `/filmlar`: «Кинозал» — тёмный зал, афиши-постеры в золотых рамах,
  фильтры по эпохам/героям; страница фильма — плеер, хронология фактов под
  видео, после просмотра микро-квиз (XP).
- **Готово:** модуль М2 получает витрину (контент наполняется в фазе 2).

### Спринт 7 — Остальные разделы ✅
- `/voqealar` — «Vaqt lentasi»: золотая ось времени с узлами-звёздами,
  события как гравированные плиты, фильтр по эпохам.
- `/testlar` — «Sinovlar»: выбор эпохи → выбор «оружия» (кинжал/меч/сабля =
  Oson/O'rta/Qiyin) → тест.
- `/kutubxona` — «Xazina»: карточки фактов на пергаменте с сургучной печатью
  источника, фильтры по героям и эпохам.
- `/profil` — «Yutuqlar zali»: медальон ранга, золотой XP-бар, лестница званий,
  медали (полученные — золотая рамка, остальные — с прогрессом).
- Общие `lib/eras.ts` и `ui/FilterChip.tsx` вместо дублей в четырёх файлах.
- **Готово:** весь продукт в единой системе.

### Спринт 7 — исходный план
- `/voqealar`: лента времени как золотая ось с гравюрами.
- `/testlar` + `QuizRunner`: «Синовлар» — уровни сложности как клинки

- **Готово:** весь продукт в единой системе.

### Спринт 8 — Полировка ✅

**Контраст.** Проверен не на глаз: скрипт обходит текстовые узлы, приводит цвета
через canvas (Tailwind v4 отдаёт `oklab()` — регуляркой не разобрать), композитит
полупрозрачности с фактическим фоном и сравнивает с порогом WCAG AA. Исправлено:

| Что | Было | Стало |
|---|---|---|
| `text-dust/55…/70` (описания, счётчики) | 2.96–4.16 | ≥4.7 (`/80`, `/85`) |
| `text-zar/60…/80` мелкий текст 9–11px | 3.42–4.44 | ≥4.6 (`/85`, `/90`) |
| Надзаголовок на пергаменте `#7a5f1c` | 4.19 | 5.89 (`#5f4a12`) |
| Строка источника на пергаменте `#6b5a34` | 4.65 | 5.94 (`#5c4a1e`) |

Оговорка метода: элементы на градиентном фоне (золотые кнопки, карточки-врата,
пергамент) дают ложные срабатывания — фон считается по `background-color`, а он
прозрачный. Для них цвета посчитаны вручную по крайним стопам градиента.

**Фокус.** Кольцо перечисляет типы элементов (`a:focus-visible`,
`button:focus-visible`, …) — одиночный `:focus-visible` на `<button>` проигрывал
системному кольцу Chrome. Проверено: 2px `--tt-zar-bright`, offset 3px.

**Движение.** Параллакс героя сведён к двум группам вместо шести отдельных слоёв;
`will-change` снят с вращения мандалы. Параллакс, вращение и пыль включаются
только на ≥1024px и отключаются по `prefers-reduced-motion: reduce`.

**Шрифты.** Baloo 2 удалён (не использовался), Cinzel — только 600/700,
Cormorant — только italic 400. В сборке 14 файлов woff2.

**Маскот.** На мобильных уменьшен до 64px, пузырь ужат и стал кликабельным
(закрывается нажатием), чтобы не держать контент закрытым.

### Спринт 8 — исходный план
