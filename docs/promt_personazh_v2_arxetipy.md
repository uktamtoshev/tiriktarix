Расширь систему персонажа до версии 2.0. Новый флоу: регистрация → выбор пола (юноша/девушка) → **выбор типажа** (воин, кочевник, дворянин, полководец, обычный парень / царица, воительница, кочевница, учёная, обычная девушка) → **конструктор персонажа**, где экипировка имеет материальные линейки (медь → серебро → золото), а открывается она **прохождением заданий и тестов**, не только уровнями. XP по-прежнему не тратится. Работай по плану с todo; реализацию крупных блоков начинай после короткого плана мне на подтверждение.

## 2. Типажи (архетипы)

Типаж — это выбор идентичности, поэтому **все типажи доступны сразу и бесплатно**; наградой остаётся экипировка. Смена типажа и пола — свободная, в профиле.

| код | Юноши | код | Девушки |
|---|---|---|---|
| jangchi | Jangchi — воин, широкие плечи | jangchi-qiz | Jangchi qiz — воительница |
| kochmanchi | Ko'chmanchi — кочевник | kochmanchi-qiz | Ko'chmanchi qiz — кочевница |
| amirzoda | Amirzoda — дворянин | malika | Malika — царица |
| sarkarda | Sarkarda — полководец | olima | Olima — учёная (обсерватория Улугбека) |
| oddiy-yigit | Oddiy yigit — обычный парень | oddiy-qiz | Oddiy qiz — обычная девушка |

(Названия можешь уточнить у меня; «Olima» вместо «красавицы» — сознательно: ценность роли, а не внешности, продукт детский.)

Типаж влияет на: телосложение базовой фигуры (jangchi/sarkarda — шире торс; параметризуй ширину, якорные точки предметов общие), базовый наряд и его цветовой акцент, головной убор по умолчанию, причёску. Экипировка из «Xazina» садится на любой типаж.

- БД: `learner_profiles.avatar_archetype` (nullable; для существующих профилей миграция проставляет `oddiy-yigit`/`oddiy-qiz` по полу).
- API: `PATCH /api/avatar/archetype` (Bearer), поле в `GET /api/avatar`.
- Регистрация: шаг 3 «Tipni tanla» — 5 карточек с превью персонажа **в полный рост** (не только голова), на мобильном — горизонтальный свайп. Смена выбора мгновенно перерисовывает превью.

## 3. Конструктор и материальные линейки

Доспех, шлем и щит получают линейки материалов: **mis (медь) → kumush (серебро) → oltin (золото)** — визуально различимые (медный тёплый, серебряный холодный, золотой = zar с сиянием). Оружие остаётся типами: qilich, nayza, kamon, oybolta и т.д. Существующие 19 предметов каталога 1.0 сохраняют свои условия (у игроков они уже открыты — условия задним числом не менять), новые добавляются к ним.

## 4. Квестовые разблокировки

Добавь к `LEVEL` / `TOTAL_XP` / `STREAK` новые типы условий, вычисляемые из уже существующих данных (`quiz_results`, `conversations`) — состояние «открыто» по-прежнему НЕ хранится, а выводится:

| unlock_type | смысл | параметры |
|---|---|---|
| QUIZ_PERFECT | N тестов без ошибок | value = N |
| ERA_TEST_SCORE | тест эпохи на ≥ V баллов | ref = code эпохи (или NULL = любая), value = V |
| HERO_QUIZ_SCORE | микро-квиз героя на ≥ V баллов | ref = slug героя, value = V |
| RIDDLE_COUNT | N решённых загадок дня | value = N |
| TALK_HEROES | поговорить с N разными героями | value = N |

- БД: `avatar_items` + колонка `unlock_ref` (nullable text). Реальные коды эпох и слаги героев возьми из сид-миграций — не выдумывай.
- `AvatarUnlockService`: по одному предикату на тип условия + юнит-тест на каждый (границы: 7/10 не открывает при пороге 8, 8/10 открывает).
- `newlyUnlocked` в ответе `/api/quiz/submit` должен ловить и квестовые условия (пересчёт до/после сабмита).

## 5. UI «Xazina» 2.0 и конструктор

- Карточка закрытого предмета показывает **задание словами**, на узбекском: «Temuriylar davri testini 9+ ball bilan yech», «3 ta testni xatosiz yakunla» — и прогресс, где он исчисляем (2/3). Это главная мотивационная петля: ребёнок видит, ЧТО выучить, чтобы получить золотой доспех.
- Фильтры: по слоту + новый фильтр «Ochilgan / Yopiq». Материальная линейка визуально группируется (медь-серебро-золото рядом).
- Превью-персонаж в конструкторе — в полный рост, мгновенно реагирует на equip и смену типажа; на регистрации и в «Xazina» один и тот же `Character` компонент.
- Момент открытия по квесту — тот же баннер + конфетти + маскот, текст: «Yangi jihoz ochildi: Oltin sovut!».

## 7. Приёмка (Definition of Done)

1. `mvn test` (включая тесты на каждый unlock-тип) и `npm run build && npm run lint` — зелёные.
2. Новый пользователь проходит: регистрация → пол → типаж → профиль с персонажем выбранного типажа в полный рост.
3. Смена типажа в профиле мгновенно меняет фигуру, экипировка остаётся надетой.
4. Сдал тест эпохи на 8/10 → в результатах баннер «Mis sovut ochildi», предмет открыт в «Xazina» и надевается; на 7/10 — не открывается.
5. Карточки закрытых предметов показывают задание словами и прогресс.
6. Старые пользователи (без типажа) получают дефолтный типаж и могут его сменить; ничего из открытого у них не пропало.
7. Equip закрытого предмета отклоняется сервером даже прямым вызовом API.

В конце — сводка: что сделано, какие скиллы использовал (и какие ставил), список файлов, 2-минутный сценарий ручной проверки.
