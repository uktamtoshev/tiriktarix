# Промт для Claude Code — голос героев (TTS, озвучка ответов)

> Скопируй всё, что ниже разделителя, в Claude Code в корне репозитория TIRIK TARIX.

---

Добавь героям голос: на каждом ответе героя в диалоге появляется кнопка **🔊 «Eshitish»**, по клику ответ озвучивается на узбекском. Это только TTS (озвучка текста) — распознавание голоса (STT) НЕ делаем, это следующий этап. Работай в два шага: сначала выбор сервиса и план, потом реализация.

## Шаг 1 — Выбор TTS-сервиса (WebSearch)

Проверь через WebSearch **актуальную** поддержку узбекского языка (uz-UZ, латиница) у сервисов: Azure Speech (у него были узбекские голоса Sardor/Madina), Google Cloud TTS, ElevenLabs, и браузерного Web Speech API. Критерии: качество узбекского, цена/бесплатный лимит, простота REST-вызова с бэкенда. Покажи мне сравнение в 4-5 строк и рекомендацию, **жди моего «ок»** — ключ сервиса добавлять буду я.

## Шаг 2 — Реализация (после одобрения)

### Бэкенд (`uz.tiriktarix.tts`)

- `GET /api/tts?text=...&hero=...` → аудио (mp3/ogg). Внутри — вызов выбранного сервиса, ключ из env `TIRIK_TARIX_TTS_KEY` (без ключа эндпоинт отвечает 503).
- **Кэш обязателен**: одинаковый текст не озвучивать дважды (ключи платные/лимитные). In-memory кэш с ограничением размера достаточно; кэшируй по хэшу (text + голос).
- Ограничь длину текста (например, 500 символов) и частоту (простая защита от спама эндпоинта).
- Если у сервиса есть мужской/женский узбекские голоса — привяжи голос к герою (всем троим сейчас мужской, но параметр заложи).

### Фронтенд (страница диалога героя)

- Кнопка 🔊 «Eshitish» на пергаментной карточке ответа героя, в стиле проекта (иконка + подпись, focus-ring, `aria-label="Javobni eshitish"`).
- Состояния: обычное → загрузка (спиннер) → играет (кнопка становится «⏸ To'xtatish»). Одновременно играет только один ответ — запуск нового останавливает предыдущий.
- **Только по клику, никакого автоплея.** Аудио создавать через `new Audio(url)`, без новых npm-зависимостей.
- **Фолбэк**: если `/api/tts` отвечает 503 или ошибкой — кнопка тихо скрывается, чат работает как раньше. Ошибка TTS ни при каких условиях не ломает диалог.
- Отказы героя (`refusalType` ≠ NONE) не озвучивать — только содержательные ответы.

## Правила

- Диалоговый движок, LLM-логику и правила достоверности не трогать вообще — TTS живёт сбоку.
- UI-текст — узбекская латиница; правила производительности README (слабые телефоны: аудио грузится только по клику).
- README: добавь короткий раздел «Голос героев» (сервис, env-ключ, как включить/выключить).

## Приёмка

1. `mvn test`, `npm run build && npm run lint` — зелёные.
2. С ключом: клик 🔊 на ответе Темура → узбекская речь; повторный клик того же ответа — мгновенно (из кэша); запуск другого ответа останавливает первый.
3. Без ключа: кнопки нет, чат работает как раньше.
4. Отказы («Bu haqda tarix sukut saqlaydi») — без кнопки озвучки.
5. В сводке: выбранный сервис, цена/лимиты, где взять ключ, сколько символов в месяц влезает в бесплатный лимит.
