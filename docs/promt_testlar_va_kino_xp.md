# Промт для Claude Code — больше вопросов, перемешивание тестов, XP за фильмы Кинозала

> Скопируй всё, что ниже разделителя, в Claude Code в корне репозитория TIRIK TARIX.

---

Три задачи в одной: расширить пул вопросов, сделать тесты каждый раз разными и наградить того, кто досмотрел фильм в Кинозале и прошёл тест по нему. Принцип достоверности №1 действует везде: ни одного вопроса «из головы».

## Часть 1 — Больше вопросов

Расширь пул `quiz_questions` для всех героев и всех эпох. Жёсткое правило: **каждый новый вопрос строится ТОЛЬКО по существующим карточкам `fact_cards`** — чтобы ребёнок мог найти ответ внутри продукта. Ничего из своих знаний не добавляй.

- На одну карточку факта можно сделать 1–2 вопроса с разных сторон (год, место, «что сделал», «кто сказал»).
- Формат как у существующих: `question_uz`, 4 варианта в `options`, `correct_index`, `explanation_uz` — в объяснении ссылайся на факт и его источник.
- Неправильные варианты должны быть правдоподобными (реальные имена/годы той же эпохи), но однозначно неверными.
- Всё одной новой Flyway-миграцией со следующим свободным номером; старые миграции и старые вопросы не трогать.
- В конце скажи: сколько вопросов было и стало по каждому герою и каждой эпохе.

## Часть 2 — Каждый раз тест разный

Сейчас вопросы и варианты, судя по всему, показываются в одном и том же порядке. Сделай так:

1. **Состав теста:** если в пуле вопросов больше, чем размер теста, — на каждое прохождение случайная выборка из пула. Поэтому Часть 1 и важна: чем больше пул, тем реже повторяются вопросы.
2. **Порядок вопросов** — случайный при каждом прохождении.
3. **Порядок вариантов ответа** — случайный при каждом показе вопроса. Правильный ответ не должен «жить» на одной и той же позиции. Реализуй так, чтобы проверка правильности осталась корректной (перемешивание на фронте с маппингом исходного индекса — достаточно), и проверь, что `explanation_uz` показывается для правильного факта.
4. **Повторное прохождение разрешено** — но XP начисляется только за первое. Повторы — тренировка: результат показываем, опыт не даём, иначе XP можно фармить одним и тем же тестом.

Это касается всех тестов: тесты эпох, микро-квизы героев в диалоге и новый тест фильма из Части 3.

## Часть 3 — XP за фильм и тест после фильма

### Просмотр: +30 XP

Ребёнок, **полностью досмотревший** фильм в Кинозале, получает 30 XP — один раз за каждый фильм.

- Внешние видео встроены через youtube-nocookie с facade-паттерном. После клика и создания iframe подключи отслеживание состояния плеера через YouTube IFrame API (postMessage, `enablejsapi=1`) — это внешний скрипт, не npm-зависимость. Новых npm-пакетов не добавлять.
- «Досмотрел» = плеер дошёл до конца (ENDED) **и** с момента старта прошло не меньше ~80% длительности видео. Простую защиту от накрутки сделай на бэке: фронт шлёт `POST /api/films/{id}/watch/start` при запуске и `POST /api/films/{id}/watch/complete` в конце; сервер сверяет время между ними с длительностью и начисляет XP только при первом честном просмотре.
- Учёт — новой таблицей (миграция следующим свободным номером): кто (client_id), какой фильм, когда досмотрел, начислен ли XP за просмотр и за тест.
- После начисления покажи дружелюбный тост в стиле проекта: «Filmni to'liq ko'rganing uchun +30 XP!» — и пусть маскот порадуется через `tellMascot()`.

### Тест после фильма

После полного просмотра предложи тест: кнопка «Bilimingni sinab ko'r» прямо на странице фильма. Формат — **как микро-квиз в диалоге с героем**: по одному вопросу, сразу видно правильный ответ и объяснение.

- **10 вопросов** из пула, связанного с фильмом: вопросы героя фильма и/или его эпохи (у фильмов есть привязка — используй её). Новых вопросов «под фильм» из головы не пиши — только пул из Части 1.
- Если в пуле меньше 10 — бери сколько есть и пересчитай пороги пропорционально (70% и 50%).
- Награда за первое прохождение: **7–10 правильных → 30 XP, 5–6 → 20 XP, меньше 5 → 0 XP** (и подбодрить: «Filmni yana bir ko'rib, qayta urinib ko'r!»).
- Повторные прохождения — без XP, вопросы и варианты перемешаны (Часть 2).
- XP за просмотр и XP за тест — независимые: можно получить 30 за просмотр и 0 за тест.

## Правила

- Весь UI — узбекская латиница; тексты в стиле существующих (дружелюбно, «сен»).
- XP не тратится никогда; новые начисления идут в общий счёт уровня, `newlyUnlocked` в ответах — как в квизах.
- Ничего не ломать: существующие тесты, диалоги, Кинозал (facade, verified-логика), уровни и разблокировки.
- Никакого сбора PII; учёт только по анонимному client_id.
- `mvn test` дополни тестами на: одноразовость XP за просмотр, одноразовость XP за тест фильма, пороги 7/5, честность проверки времени просмотра.

## Приёмка

1. `mvn test`, `npm run build && npm run lint` — зелёные.
2. Два прохождения одного теста подряд → разные вопросы (при большом пуле) и разный порядок вариантов; результат считается правильно.
3. Досмотрел фильм → тост +30 XP; перезагрузил страницу и «досмотрел» снова → XP не начислился.
4. Тест фильма: 8 правильных из 10 → +30 XP, 5 из 10 → +20, 3 из 10 → 0; повторное прохождение XP не даёт.
5. Перемотка видео сразу в конец без просмотра → XP за просмотр не начисляется.
6. Количество вопросов выросло у всех героев и эпох; у каждого нового вопроса объяснение ссылается на карточку с источником.

В конце — сводка: сколько вопросов добавлено (таблица по героям/эпохам), какие таблицы и эндпоинты появились, как работает проверка честного просмотра.
